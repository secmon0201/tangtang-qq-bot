# 公共话题素材

Harness 保留原机器人从鸣潮官网、枝江日历收集话题素材的能力。它读取独立本地缓存，将相关内容放在本轮动态上下文；固定人格前缀不随新闻和日程变化。

- 鸣潮官网使用原官方公开新闻索引，提供标题、正文片段和资料日期；枝江日历复用 Harness 的日程解析。
- 仅在当前群的 `persona_topics` 开启时采用素材，原有关闭状态保持关闭。群资料和来源使用记录按会话和人格分别隔离；私聊使用独立个人会话。
- 素材自真实抓取起 24 小时有效。日历网络失败使用原缓存时保留真实抓取时间，不能把过期缓存重新标成今天的资料。
- 正常每六小时后台刷新；资料缺失或刷新失败时，至少间隔五分钟再尝试。网络请求在独立话题后台任务执行，不阻塞聊天、游戏或语音。
- 默认不附链接。用户追问来源时，只提供当前会话最近一次确认使用素材的精确来源链接；单纯注入素材不能作为使用证据，需要已送达答复和素材之间可观察的中文内容重叠。
- 主动聊天在 24 小时内不重复采用当前会话已使用的话题。素材采集不主动发送 QQ 消息，也不调用模型；聊天采用素材后的模型输入费用仍计入该次正常请求。

旧话题缓存及来源记录从新目录已保存的 persona 一致性快照读取，保留原抓取时间、人格和群范围。新数据独立写入 Harness 数据库的 `topics:*` 设置项，不读取或写入旧运行数据库。

实现为 `tangtang_harness/topics.py` 和 Runtime 的 `harness-topics` 后台任务；本轮采用的素材由请求 telemetry 中的 `public_topic` 记录，后台状态保存在 `topics:refresh`。
