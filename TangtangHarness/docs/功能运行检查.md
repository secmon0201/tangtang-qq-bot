# Harness 功能运行检查

本页记录 2026-10-04 的功能与初始化检查。检查区分隔离环境的行为覆盖、当前线上只读证据、主动关闭的能力，以及尚未完成的真实联调。入口存在、数据库有记录或接口返回成功，都不能单独证明业务已经向 QQ 正常投递。

本轮完整测试与修复后的部署已完成：335 项行为测试通过，前端生产构建通过，16 个只读 API 返回 200。下文区分已经部署的修复，与尚未逐项真实执行的业务。详细迁移来源见[旧功能迁移台账](旧功能迁移台账.md)，已有业务行为范围见[本地业务验收](本地业务验收.md)，历次真实切换见[实施验收记录](实施验收记录.md)。

## 2026-10-05 控制台与群边界改造

控制台默认进入“会话”，用对话气泡由新到旧展示消息，保留可展开的来源、实际请求与缓存结构。群、私聊和后台工作使用完整群名及当前范围保存的用户昵称，明确标记“群”或“私聊”；任务、状态与工具使用中文名称。统计范围默认折叠，刷新在标题或操作栏显示图标并保留原内容，避免加载提示挤动正文。

实时读取合并后续刷新，不因每个 SSE 通知取消进行中的同查询读取；切换会话才取消旧查询。默认选中的会话固定，最近活动排序变化不会自动跳群。会话身份接口直接读取当前群名、昵称和状态，不重新执行全量上下文统计。慢响应浏览器检查以 4 秒响应、每 350 毫秒刷新验证消息仍能显示、单查询最多一个请求、换群不串旧记录。

新增“发言排行”和“群与集群”：可直接查询本群或集群的日、周、月及累计发言榜，查看完整群名、排行缩写、集群成员和已归档群，并编辑群开关及过滤名单。缩写仍用于发言榜，查重与公告等后台群选择保留完整群名。

63 项本地工具中，45 项有实际可调输入，现提供中文参数、选项和说明；其余工具不伪造参数。白名单、档案目标、知识领域、日程视图、群开关、系统参数及被动互动概率和冷却可从表单操作。原本只解析中文管理指令的工具提供对应输入框及用法。工具返回结果默认仅显示在控制台，工具本身的配置和业务操作仍会生效。

23:50 日榜按所属集群汇总，启用推送的各成员群收到相同集群总榜；独立群保持本群榜。机器人离群后归档历史，默认查重、自动任务、投递及活跃范围排除该群。当前成员列表同步和离群事件均维护这一边界；查看归档记录不会重新启用业务。

启动和 OneBot 重连后，群自动任务等当前连接的有效群列表同步完成才恢复；失败保留历史状态并继续暂停群自动执行。同步在有界后台任务中运行，私聊继续工作；旧连接迟到的列表不会恢复新连接的任务。Core 上传、撤回和禁言在等待完成后再次核对群状态。

本次身份、倒序、集群总榜及离群排除验证使用合成群、临时数据库和模拟平台，不将其称作真实 QQ 推送成功。下文保留 2026-10-04 已完成的现场证据；新的 23:50 实际投递仍以对应时段的 QQ 回执确认，不为检查额外群发榜单或测试消息。

最终 Harness 全量行为测试为 **608 项通过**，前端生产构建通过，根仓库要求的七项校验全部通过。根仓库 pytest 为 1655 项通过、1 项失败：已有的上游安装脚本修改不满足旧测试的命令文本断言，本轮未改动该旧系统脚本。仅重启 Harness 后，线上只读接口确认 live、OneBot/Core 连接及群同步正常，集群成员和日榜推送开关保持，离群目标已归档并从当前排行中排除。

## 补缺与收尾方式

生产只使用 `prepare_config` 计算来源候选值，不全量执行配置导入。native 设置仅添加尚不存在的 key；`passive:<group>` 字典只添加缺字段，不替换已有字典。当前模型、容量、接口、密钥来源、群范围和用户新设置保留。原业务表不重新合并，旧数据库不写入，历史待发送任务不补执行。

首次检查发现 10 项 native 字段遗漏，后续确认整点三项同样遗漏。部署时已补齐 13 项 native 设置和 6 份被动互动配置的缺字段，重新核对缺项为零；原有字段没有覆盖。QQ 连接、后台队列与额度初始化已复查，实际整点等调度回执仍需相应时段继续核对。关闭项和需要手工操作的外部能力保持明确状态，不为形成“全部正常”结论自动启用。
