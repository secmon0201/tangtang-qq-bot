# 旧插件功能接线核对

本表按旧 `bot/application/plugin_registry.py` 的 29 个来源逐项核对实际入口、业务执行、后台和交付。它补充[迁移台账](旧功能迁移台账.md)，不是仅按工具名称或静态清单认定功能可用。隔离测试使用新目录临时数据库、合成身份和平台模拟端；真实 Core、语音和生产连接的结果另见[运行说明](迁移与运行边界.md)。

26 项有效来源保留业务；旧 NTE/鸣潮本地接管和官方 QQ 备用传输共 3 项按已确定范围排除。未启用的 AI 画像、主动聊天、免呼叫续聊及缓存预热不因修复自动开启。
