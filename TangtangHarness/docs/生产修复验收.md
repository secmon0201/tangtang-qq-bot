# Harness 生产功能修复验收

本次只修改 Harness。旧 NoneBot、旧数据和游戏上游保持独立；退役活动、问卷、官方 QQ OpenAPI 与本地 NTE/鸣潮接管继续按迁移计划排除。

## 旧业务入口与接线修复

| 业务 | 修复后的行为 | 行为验证 |
| --- | --- | --- |
| 游戏命令路由 | `#nte`、`#ww`、旧裸前缀、大小写与 `bot` 后缀按完整原文交给 Core；参数中的“然后”等文字不再被本地组合解析截断 | 整条转发、旧前缀与错误前缀测试 |
| 发言排行 | 命名集群的发言统计/统计别名、日周月总榜参数恢复；未知周期先澄清；图卡附本地排行网页链接 | 旧别名和真实本地统计查询测试 |

本地业务处理器继续直接返回业务内容，不进入聊天模型；上述初始化和维护文件只读写 Harness 拥有的数据目录。所有旧指令均以当前有效源码行为对照，未用注册数代替可用功能验收。

| 需求 | 已完成的行为 | 验证依据 |

| 群聊触发 | 普通自然语言须呼叫娅娅或真实 @ 机器人；@ 其他人不触发；明确业务命令正常执行 | 群聊触发与零模型本地路由测试；生产主动聊天、免呼叫续聊均关闭 |

真实 Core 与媒体验证采用本地截获发送，QQ 测试发送为零，没有重复执行生产操作。模型媒体实验独立保存请求，价格未配置时仅记录实际 token；不会把缓存未知字段写成零。

原超时上下文的流式复测输入 30923、输出 60、缓存读取 8960 token。该结果只证明此上下文完成请求，不代表总体命中率提升，也不承诺供应商永不超时。后续失败保持后台可见、QQ 静默。
