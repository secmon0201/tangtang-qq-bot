# QQ 机器人分角色使用手册

本手册按使用者身份组织。群内命令的基本规则如下：

- 普通用户：使用 `#指令 [参数]`；权限由具体命令决定。
- 活动管理员：使用 `#指令 [参数]`。身份来自 `.env` 的 `ACTIVITY_ADMIN_IDS`，或活动有效群内的群主、群管理员；后者可被 `ACTIVITY_ADMIN_BLACKLIST_IDS` 排除。
- 超级管理员：身份来自 `.env` 的 `BOT_OPERATOR_IDS`，同样使用 `#指令 [参数]`。
- 私聊也使用 `#`；权限仍然生效，不会绕过活动范围和角色权限。

## 一、普通用户

普通用户可以在已开启活动功能的群中执行：

```text
#活动大厅
#活动详情517
#活动详情：517
#查看名单 517
#获奖名单#517
#报名517
#报名 517
#报名：517
#报名#517
#取消报名517
#我的活动
```

活动 ID 前可以使用空格、中文冒号或 `#`。普通用户不能创建、修改、取消或提前结束活动。

普通用户帮助：

```text
#活动帮助
```

该帮助只展示查看、报名和退出报名，不展示管理员命令。

## 二、活动管理员

`ACTIVITY_ADMIN_IDS` 中的成员，以及活动有效群内的群主、群管理员，都是活动管理员。自动识别的群管理员需在活动有效群内使用管理命令；`ACTIVITY_ADMIN_BLACKLIST_IDS` 中的成员不会获得该自动权限。活动管理员只能操作自己创建的活动。

活动管理员帮助：

```text
#活动管理员帮助
```

创建活动：

```text
#创建活动 活动名：测试活动
开始时间：2026-07-26 18:30
结束时间：2026-07-26 20:30
类型：抽奖
说明：活动说明
奖项：一等奖=1；二等奖=2
参与群：123456789,2548761
隐私：公开
```

修改活动：

```text
#修改活动 活动ID：517
活动名：新的活动名
结束时间：2026-07-26 20:30
隐私：公开
```

每项单独换行，未填写或留空的字段保持原值。活动管理员不能管理其他人创建的活动，也不能修改进行中的活动；进行中的活动仅超级管理员可以修改，修改后会通知所有参与群。旧的竖线格式仍可使用。

取消或提前结束：

```text
#取消活动 ID 原因
#提前结束 ID
```

目标参与群必须属于当前活动功能范围。修改参与群后，退出群收到范围变更图片，新群和保留群收到完整活动更新图片。

## 三、超级管理员

超级管理员可以管理全部活动、查重白名单、功能范围、被动互动参数和系统状态。群内命令统一以 `#` 开头。

超级管理员帮助：

```text
#超级管理员帮助
```

兼容命令：

```text
#管理员帮助
```

超级管理员帮助图片会动态显示：

- 当前超级管理员和活动管理员名单；
- 全部管理群数量及群号；
- 统计、查重、游戏、活动、被动互动、整点报时的逐项范围；
- 功能范围热更新命令；
- 活动管理命令；
- 白名单和被动互动管理命令；
- NoneBot 地址、数据库路径和本地维护命令；
- 不显示 OneBot token、AI API Key、QQ 密码或其他凭据。

查看所有功能范围：

```text
#功能范围 列表
```

该列表会展示全部 `MANAGED_GROUP_IDS`，即使某群没有开启任何具体功能，也会显示为全部关闭。

## 四、帮助和交互边界

当前核心交互使用 OneBot v11 标准文本、图片和合并转发消息。NapCat 版本之间的自定义键盘、Markdown 按钮和回调事件并不统一，按钮点击也可能只产生普通消息，不能可靠映射到某个操作。因此活动创建、修改和管理暂不依赖按钮。

本机网页地址如 `127.0.0.1` 只能由机器人所在电脑访问，群成员无法直接打开；若开放公网地址，还需要单独的登录鉴权、HTTPS、过期链接和访问审计。当前先使用角色帮助图片加宽松的公开活动命令，避免引入额外公网暴露面。

## 五、重启和配置

修改 `ACTIVITY_ADMIN_IDS`、`BOT_OPERATOR_IDS` 或其他启动配置后，双击项目根目录：

```text
restart_nonebot.bat
```

该操作只重启 NoneBot，不重启 NapCat。功能范围命令和被动互动参数写入本地 SQLite，可热更新并在重启后保留；糖糖主动回复参数由 `#糖糖主动回复` 指令实时写回 `.env`，同样在重启后保留。
