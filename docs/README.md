# 文档总览

这是本仓库文档的唯一入口和全功能地图。运行行为以代码、`.env.example` 和自动化测试为准；文档与它们冲突时必须在同一提交中修正。每个功能有且只有一份功能文档，跨功能的安装、权限和运维规则放在共享文档。

## 快速开始

- [安装与运行](运维-安装与运行.md)：安装、启动、重启、关闭、watchdog、备份和故障排查。
- [糖糖展示站](运维-糖糖展示站.md)：`https://tangtang.secmon.cn/` 机器人主页的内容边界、本地预览和固定隧道部署。
- [公开展示站模块化维护](运维-公开展示站模块化维护.md)：页面、板块、更新日志、暂存构建与原子发布流程。
- [权限与范围](功能-权限与范围.md)：普通用户、活动管理员、超级管理员和功能群范围。
- [全部 `#` 指令清单](全部#指令清单.md)：当前命令、参数、别名和权限的全局速查，由测试守护。
- [启动工具说明](../启动工具/README.md)：全部中文双击入口及其影响范围。

## 维护要求

- 新增功能必须新增一份 `功能-*.md`，并在上方功能地图登记一行；删除功能同时删除文档和登记行。
- 本索引由 `scripts/validate_docs.py` 强制全覆盖，任何 `docs/` 下的文档漏登记都会失败。
- 任何 `#` 指令增删改必须在同一改动中同步 [全部 `#` 指令清单](全部#指令清单.md)。
- 历史提案、实施交接稿和固定日期运行快照不属于有效文档，不应重新加入。
