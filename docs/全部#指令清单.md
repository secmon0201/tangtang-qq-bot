# 全部 `#` 指令清单

更新时间：2026-09-06

本清单以当前运行的 **OneBot / SnowLuma** 模式为准。机器人指令统一以 `#` 开头，**不需要 @ 机器人**。`#丢给 @成员` 中的 `@成员` 是游戏目标，不是指令前缀。

## 使用范围与权限

- 新加入的群自动登记为独群。群主、群管理员和超级管理员可维护当前群开关；集群只由超级管理员在私聊维护。
- 一般指令仅在对应功能已对当前群启用时响应；小游戏还要求全局运行条件和本群开关均开启。今日老婆独立于小游戏和直播防护。
- 下文的 `[参数]` 可省略，`<参数>` 必填；同一行用 `/` 分隔的名称都可以使用。
- 直播期间会暂停当前群的小游戏。普通用户会收到直播提示；管理员和超级管理员仍可使用管理指令。

## 今日老婆（所有人）

今日老婆为独立群内社交功能，默认在全部受管群启用；不受小游戏开关和直播暂停影响。
仅最近三天内有发言的群成员会进入候选池。抽取为加权随机：当日发言、双向信号和新鲜感会提高概率；当天被抽中的对象会快速降权，双向关系会获得显著的戏剧性提升。每天会先等概率抽取现实日常、轻奇幻或强幻想中的一种群主题；主题机制会改变回应、助攻、误会修复和第三方扩散的倾向。

领取后不再提供主动互动指令。非首位参与者执行玩法命令时，有概率静默触发一位其他参与者的有效互动；靠近、倾听、回应、修复和助攻仍遵守既有前置条件。每天 11:30-12:00、17:30-18:00、23:00-23:30 进行三轮错峰集体互动，每位有效关系的主动领取者各自动作一次；前两轮分别推进到第二、第三幕，第三轮完成后收官封场。即时变化只在个人缘分与群缘分中查看。

| 指令 | 用法 | 说明 |
| --- | --- | --- |
| `#今日老婆` / `#今日缘分` |  | 每人每天随机抽取一位当前群成员，返回头像与当天缘分故事；重复发送只查看当天结果，不会重抽。 |
| `#强取 @群友` | 必须真实 @ 一位当前群内、且不是自己的群友 | 定向抽取指定群友；已有当天老婆时失败。离婚后仍遵守当天仅一次重抽规则。 |
| `#离婚` / `#解缘` |  | 结束自己当前的今日关系；关系不会从群像删除，会以灰色虚线和“曾经好感”保留。当日可再抽取一次，第二次解缘后不能继续抽取。 |
| `#我的缘分` / `#我的老婆` | 可加正整数页码 | 查看今天主线、被谁写进故事、好感与互动镜头；`#我的缘分 2` 起可翻阅永久个人留档。 |
| `#群缘分` / `#群老婆` | 可加 `历史` 或 `YYYY-MM-DD` | 查看当天关系图，包含仍在榜上的离婚关系；最近 7 天可查看完整群像，早期日期公开关系/互动/离婚摘要。 |

## 发言排行

以下指令仅在 `STATS_REALTIME_ENABLED=true` 时加载。普通排行只读当前群；加入私有集群的群可额外查询当前集群。日、周、月、总榜均显示前 100，图片显示头像和昵称，不显示 QQ 号。

| 指令 | 用法 | 说明 |
| --- | --- | --- |
| `#发言排行 [日\|周\|月\|总]` / `#发言榜` / `#发言统计` / `#统计` | 参数省略时为日榜；日/周/月/总也支持直接连写 | 当前群内发言排行。历史说明以糖糖加入当前群的日期为准。 |
| `#集群发言排行 [日\|周\|月\|总]` / `#集群发言榜` / `#集群发言统计` / `#集群统计` / `#<集群名>发言排行 [日\|周\|月\|总]` / `#<集群名>发言统计` | 参数省略时为日榜；日/周/月/总也支持直接连写 | 仅集群成员群可用，合并当前集群；命名形式按 SQLite 中的集群名或别名查找。若集群名为“A海岸”，`#A海岸发言排行日`、`#A海岸发言统计日` 均可用。 |

## 发言档案

发言原文统一保存在糖糖本地聊天记录库（`tangtang.db`）。记录与搜索限定当前群；画像按当前群域读取。群内成员可触发画像，私聊仅超级管理员可用。

| 命令 | 用法 | 说明 |
|---|---|---|
| `#发言记录` | `#发言记录 QQ号 [页码]` | 以图片查看该用户在当前群的已存档纯文本发言，每页最多 100 条。 |
| `#发言搜索` | `#发言搜索 QQ号 关键词 [页码]` | 以图片在该用户当前群的历史存档中搜索关键词。 |
| `#发言画像`、`#画像` | `#发言画像 QQ号`、`#画像 QQ号`、`#发言画像 @成员`、`#画像 @成员` | 分析当前群域记录；独群只读本群，集群读取当前集群。画像需有超过 100 条已存档纯文本发言。 |

## 非当前传输模式的功能

- 官方 QQ OpenAPI 模式的 `#官方状态` 等指令不属于当前 OneBot / SnowLuma 运行模式，因此不在本清单的可用指令中。
- 异环 NTEUID 与鸣潮 XutheringWavesUID 分别支持带或不带 `#` 的 `nte`/`ww` 前缀且不区分大小写；原神 `gs`/`ys` 与其他游戏前缀保持关闭。

## 维护要求（必须执行）

新增、删除或修改任何 `#` 指令时，必须在**同一个改动**中同步维护本文件，包括：

1. 新增或修改 `on_command` 的名称、别名、权限或可用范围；
2. 新增或修改由消息正则分发的小游戏 `#` 指令；
3. 修改现有指令的参数格式、响应行为或启用条件；
4. 启用、停用或切换传输模式下的指令集。

`tests/test_command_catalog.py` 会校验当前 OneBot 已加载插件内的显式 `on_command` 名称和别名均已出现在本文件，也会覆盖小游戏消息入口的关键指令。修改指令后应运行：

```powershell
pytest tests/test_command_catalog.py
```

实现来源：`bot/application/plugin_registry.py` 的唯一注册清单，以及 `bot/plugins/commands.py`、`bot/plugins/group_settings.py`、`bot/plugins/mini_games.py`、`bot/plugins/zhijiang.py`、`bot/plugins/hourly_announcements.py`、`bot/plugins/a_coast_archive.py`。
