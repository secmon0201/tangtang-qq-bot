# 功能：群域发言档案与画像

发言档案按群记录纯文本消息，并按调用场景限制读取范围。源码不预设任何集群；所有命名集群沿用同一套群域规则。

## 指令与范围

| 指令 | 范围 | 说明 |
| --- | --- | --- |
| `#发言记录 QQ号|@成员 [页码]` | 当前群 | 查看已存档纯文本，每页最多 100 条。 |
| `#发言搜索 QQ号|@成员 关键词 [页码]` | 当前群 | 在当前群历史中搜索关键词。 |
| `#发言画像 QQ号|@成员` / `#画像 ...` | 当前群域 | 独群只读本群，集群读取当前集群。 |

记录和搜索只允许超级管理员私聊或现有命令权限边界内使用；群内画像要求调用者与目标符合当前群权限。群关闭“发言档案”后，群成员不能主动调用，但已有历史数据不会删除。

## 画像更新

- 画像需有超过 100 条已存档纯文本发言。
- 本地统计包含 24 小时发言分布和六维文本特征；AI 正文只处理尚未用于画像的新原文。
- 同一原文只会进入一次 AI 画像更新。没有新增发言时直接复用已有画像。
- AI 不可用时仍可生成本地统计摘要。
- 每名用户同一时间只允许一个画像任务，全局并发受 `PROFILE_MAX_CONCURRENT` 控制。

## 隐私与存储

- 原文保存在本机 `tangtang.db`，不得提交 Git 或暴露到公开网页。
- 公共排行只展示计数、昵称和头像，不提供原文接口。
- API 密钥只保存在本机 `.env`；不得写入群消息、文档、日志样例或仓库。
- 图片顶部统一 `AK-BOT FUNCTION`，底部署名统一 `AK bot`。

画像 AI 复用 `TANGTANG_*`，可由 `PROFILE_*` 单独覆盖模型、超时、输入输出和证据合并参数。完整命令见 [全部 `#` 指令清单](全部#指令清单.md)。
