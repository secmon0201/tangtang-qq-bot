# 功能：群域统计与发言排行

发言统计以单个群为基础，以 SQLite 私有集群为可选扩展。源码不预设任何集群名称或成员。

## 查询范围

| 指令 | 范围 |
| --- | --- |
| `#发言排行 [日|周|月|总]` | 当前群；`#发言榜`、`#统计` 为别名。 |
| `#集群发言排行 [日|周|月|总]` | 当前集群；`#集群发言榜`、`#集群统计` 为别名，仅集群成员群可用。 |
| `#<集群名>发言排行 [日|周|月|总]` | 指定当前群所属集群；同样支持“发言榜”和“统计”后缀，名称和别名不区分 ASCII 大小写。 |

独群只能看到本群数据。集群成员群可以查看当前集群及成员群切片。以名为“A海岸”的集群为例，`#A海岸发言排行` 会通过通用名称查找得到与 `#集群发言排行` 相同的结果，不是硬编码别名。调用群不属于目标集群时拒绝查询。群内关闭发言榜查询只阻止本群主动调用，不把该群从集群统计中移除。

## 23:50 推送

- 每个群独立维护“23:50 发言榜推送”开关。
- 独群开启后，在 23:50-23:59 发送本群日榜。
- 集群成员群开启后，在同一窗口发送当前集群日榜。
- 窗口内重连只补发尚未成功的目标群，避免重复发送。
- 图片与主动查询使用同一份排行 payload 和同一网页模板。

## 历史说明

每个群的页面和图片使用该群实际登记的 `joined_at` 日期，文案格式为“历史数据最早自 YYYY-MM-DD”。例如糖糖于 2026-08-29 加入某群，页面显示“历史数据最早自 2026-08-29”。不再对外写死统一起始日期。

## 网页链接

每个群域拥有不可猜测的公开令牌。主动查询和 23:50 推送都附带该群域的链接：

`https://bot.example.invalid/ranking/<令牌>/?scope=day`

独群令牌只返回本群日、周、月、总榜。集群令牌可以切换当前集群及成员群。群加入、移出、退群、重新加入或集群解散时，相关旧令牌立即轮换；空群域令牌不可访问。`/community*`、无令牌 `/ranking/` 和旧短链 `/s` 均返回 404。

## 渲染与数据

- 排行显示前 100 名，保留头像、昵称和统计值，不显示 QQ 号。
- 集群比较图保留成员群头像与发言量；成员群按本机通用管理群顺序展示，其余群按群号稳定排序。
- 网页截图是 QQ 图片的主渲染路径，Pillow 保留为降级方案。
- 活跃图片顶部统一 `AK-BOT FUNCTION`，底部署名统一 `AK bot`。
- SQLite 保存统计、群域与推送幂等状态；公开 API 只读。
