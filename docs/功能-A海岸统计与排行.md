# 功能：A 海岸发言统计与排行

实时发言计数和榜单，范围固定为五个 A 海岸群：1128870029、1077416717、1083457871、1090284567、278824712。其他群不计数。

## 可用范围

五个 A 海岸群内所有用户均可使用；超级管理员可私聊查询 `#A海岸发言排行 总`。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `#发言排行 [日/周/月/总]` | 当前群发言榜，参数省略时为日榜；`#统计`、`#发言榜` 兼容。 |
| `#A海岸发言排行 [日/周/月/总]` | 五群合并榜；`#A海岸发言榜`、`#A海岸统计` 等别名兼容。 |

## 行为规则

- 只保存 QQ 号、最后昵称、每日发言次数和消息去重标识，不保存消息内容。
- 日、周、月、总榜均显示前 100；图片显示头像和昵称，不显示 QQ 号。
- 五群合并榜中每位用户只显示其在统计窗口内发言次数最高的一个完整群名；次数并列时按 A 海岸固定群顺序判定。
- 每天 23:50-23:59 自动向五个群各发送一次 A 海岸日榜；窗口内重连会补发未成功的群。
- 记录自 2026-07-28 起；A 海岸范围固定，不能用 `#功能范围` 修改。

## 配置

- `STATS_REALTIME_ENABLED=true`：加载监听与排行命令；关闭后不加载。
