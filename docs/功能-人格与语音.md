# 人格与语音

同一 QQ 账号按群选择糖糖或达妮娅，默认糖糖。人格、聊天模型和声线分别配置，沿用现有呼叫、主动接话、费用总控和群开关。

聊天调度每群最多一条运行任务，明确呼叫最多再等待两条，按接收顺序处理；主动接话不排队，群内已有任务或等待呼叫时跳过。不同群可独立处理，全局最多 32 个活跃群。队列满、重复消息、停机和上下文失效都有原因日志；排队请求开始前复核冻结的人格与配置，切换后旧请求不执行。排队不绕过原有去重、呼叫忽略或费用开关。

每个排队请求独立保存 NoneBot 事件、机器人及发送节奏上下文；执行时恢复该请求自己的上下文，避免沿用首条消息造成回复对象或过期判定错误。队列容量是明确的接纳上限：同群同时超过三条时，超出部分会被拒绝并记入日志，不承诺所有突发呼叫都获得回复。

`logs/bot.out.log` 的 `Chat trace` 记录接收、入队、开始、结束或丢弃。`data/tangtang/usage` 的模型结果及发送记录携带相同 `request_id`（群号:原消息 ID）和 `message_id`；额外诊断事件不重复累计 token。失败记录异常类型，发送成功记录平台消息 ID。

## 指令

| `#群设置 人格成长 开` / `关` | 本群公共观点、用语与关系情绪成长。 |
| `#群设置 角色表情 开` / `关` | 糖糖使用 QQ 标准表情，达妮娅使用审核后的角色图。 |
| `#群设置 话题素材 开` / `关` | 固定来源的近期素材。 |
| `#群设置 语音 开` / `关` | 本群语音，仍需当前人格已绑定声线。 |
| `#人格 成长 列表` / `停用 <编号>` | 群管理员查看或停用本群当前人格的公共成长记录。 |

| `#系统设置 人格后台整理 状态` / `开` / `关` | 超级管理员在私聊管理后台整理。 |

糖糖响应“糖糖”或真实 @；达妮娅响应“娅娅”或真实 @。“达妮娅”不是呼叫词，适配器的 `to_me` 标记本身也不算 @。叫错名字按普通群聊处理，仍可能符合主动接话条件。切换时公告，日常不加角色前缀。

首版不提供临时点名切换、个人专属人格或私聊陪聊。达妮娅按初识开始，不继承糖糖关系。可完整讨论剧情，日常不反复解释虚质设定。

普通文字回复的表情候选以 60% 概率进入本地抽选，并非每条回复都有 60% 概率带表情。明确呼叫“娅娅，发个表情包”跳过呼叫忽略和 60% 门槛，在友善微笑中选择；“发个开心表情”按类别选择，“发个手动微笑表情”或“发个expr_026表情”按名称或 ID 点播。点播仍受群开关、资源和消息去重限制。明确要求不要表情时不发送；语音与沉默不附图。确定附图后，50% 概率与第一条文字合成同一条 QQ 消息，其余情况在文字成功后单独发送；文字失败或送达不明时不继续补图。

角色图支持 GIF、WebP、PNG、JPG 和 JPEG；优先读取目录登记的文件，未登记文件名的兼容资源按上述扩展名顺序查找。文件放在 `bot/resources/personas/denia/expressions/`，发送原文件，不截图、不取首帧、不转为 JPG；动画最终显示效果由 QQ 客户端及 OneBot 实现决定。更新资源或语义目录后重启 NoneBot，以重新冻结资源版本；保留来源、版本和授权说明。仅放入陌生文件名不会自动登记。

`expression_catalog.json` 保存 49 张图的逐图视觉观察、中文名称及别名、画面文字、情绪解释、主观强度、适用/避用场景、语义组、文件哈希和 GIF 已查看帧号。标注由维护助手直接查看图像及关键帧后完成，不按文件名生成，不增加人工审批阶段；情绪解释允许后续修订，没有伪造数值置信度。目录版本随人格资源哈希冻结；完整元数据启动时同步 SQLite 的 `expression_metadata`，基本中文名称兼容保存在 `expression_catalog`。聊天只传文字目录，不读取图片上传给聊天模型。带“杂鱼”文字的图只允许明确点播，不能作为普通微笑替代项。

模型输出 `expression` 首选 ID 和 `expression_candidates` 最多三个替代 ID；语义组仅供参考，替代项允许跨组轻松联想、接梗或呼应气氛，不要求与正文逐字对应，但仍须遵守避用场景，不用嘲讽图回应真实痛苦或严肃求助。目录每轮随机排列，消除固定位置优先。程序验证允许 ID、资源与明确点播限制，只在模型给定的合适候选中抽选，不为了凑数自动扩展到整个情绪类别。普通抽选和类别点播排除本群、本人格近 24 小时最后两次成功发送的图片，余下候选的权重为 `1 / (1 + 近24小时成功次数 / 3)`；全部被排除时不附图。准确点播某个唯一 ID 或名称可重复发送。各群、各人格的计数隔离，成功回执才增加计数，重启不丢失。

`expression_events` 按请求记录候选、最终 ID、概率值、排除原因、权重、目录版本和平台消息 ID。状态区分 `skipped`、`selected`、`sending`、`delivered`、`failed`、`uncertain`、`cancelled`；无回执或网络异常不计成功、不自动重发。中断后遗留的 `sending` 也是未确认状态。人格切换、功能关闭和请求失效后不继续发送。离线只读查看当天排名：`.\.venv\Scripts\python.exe -X utf8 scripts/report_expressions.py`，可加 `--day YYYY-MM-DD`、`--group 群号`。导入的旧平台回执只有成功次数，没有当时的候选决策，不可据此推测未选原因。

## 记忆与成长

糖糖原历史库继续使用，达妮娅历史位于本地 `data/personas/denia-history.db`；选择、公共成长、预算和送达记录位于 `data/personas/state.db`。同一人格按 QQ 账号跨群认识用户，共享稳定个人资料、熟悉程度和对该用户的短时情绪；不同人格仍独立。群内话题、称呼约定、专有梗和当前氛围保留本群范围。公共列表不显示私人记忆。

相关时可召回与当前用户在其他群的至多两条简短互动片段，不读取其他人的跨群对话；涉及引用、第三人、敏感内容或本群限定的片段不自动跨群使用。话题匹配采用保守的文字相关度，不能据此推断缺少记录的经历。最近上下文和未完成问题仍按群读取。

“忘记草莓”默认对当前人格在所有群的该用户资料生效，并阻止旧历史和后台整理重新引入相关内容；“只在本群别提草莓”仅限制本群使用。“恢复记忆草莓”或本人明确重新要求记住可恢复。原始审计记录保留，忘记不等于删除所有日志。遗忘和范围变更会使该人格已在途的旧记忆回复失效，包括迟到语音。

稳定观点及通用表达允许跨群成长，专有表达留在本群。`#人格 成长 列表` 标记跨群/本群条目；群管理员停用跨群条目仅屏蔽本群。超级管理员可用 `#人格 成长 全局 列表`、`#人格 成长 全局 停用 <编号>`、`#人格 成长 全局 回退 <编号> <版本>` 管理共享条目。管理员不能用这些公共成长命令修改私人资料。

迁移先执行 `python scripts/migrate_persona_memory.py` 只读预览，停止 NoneBot 后以 `--mode apply` 备份并增量迁移。旧表保留，重复执行不重复累加；初始熟悉度取同用户各群最大值，初始态度取最近记录，个人临时情绪从中性开始。`--mode rollback` 退回群内资料读取，`--mode enable` 恢复共享读取；两者保留新增资料和遗忘限制。旧群成长不批量升为全局。运行时数据及备份不提交。

只有成功送达的互动提供成长证据，旁观群聊只作临时上下文。新观点和修订需要两个自然日、三次不同互动的原文证据。稳定身份、剧情事实和核心性格不自动修改，旧历史不批量重解释。停用项不会被整理自动启用，回退产生新的历史版本。

情绪变化有界，偏离平静的程度每六小时衰减一半。关系保持群友式熟悉，不自动形成恋爱或排他关系。成长通过表达自然体现，不播报等级变化。

## 语音行为

TTS 只转换确定的文字并发送。达妮娅绑定 `villia/dania` v2ProPlus 声线；糖糖暂不绑定。以后指定糖糖自己的模型、参考音频和台词即可使用同一接口，不覆盖管理员已关闭的开关。

优先级：沉默 → 能力与开关检查 → 用户明确要求文字 → 用户主动要语音时由人格决定 → 普通回复随机尝试。拒绝语音后禁止随机覆盖。语音回复只有一条录音，不附同文文字或角色表情；代码、链接、表格及过长内容使用文字。

默认随机概率 10%，同群随机间隔至少 10 分钟；主动点播不受这两项限制，但仍可被人格拒绝。默认每日每群 12 次、全局 60 次尝试。随机参数与额度通过本地管理工具调整。

明确请求语音（例如“娅娅用语音跟我说句话”）跳过呼叫的随机忽略，由人格决定是否答应；仍遵守沉默、去重、费用和资源限制，不保证每次都发语音。用量日志中的 `voice_decision` 记录可用状态及发送形式，`voice_result` 记录合成发送结果；普通呼叫的随机忽略标注 `call_ignore_probability`。

例如：`.\.venv\Scripts\python.exe scripts/persona_settings.py --set speech_probability 0.1`。不带参数查看可调项与当前值。声线文件更新由后台重新校验加载，任何已关闭的群开关保持不变。

排队和合成统一最多 30 秒，单并发、最多两项等待；后台负责启动和健康检查，聊天不等待冷启动。随机语音失败回退文字，接受点播后失败会简短说明。QQ 送达不明时记录为不确定，不重试或补发。成功送达的转写才进入历史；人格切换后的迟到语音不发送。

接口可访问后还需后台实际试合成并校验音频，完成前保持“准备中”。预热使用同一个合成工作槽，不发送消息、不记录互动、不消耗群语音尝试额度。预热失败后至少等待 60 秒再重试；超时后仍在执行的任务继续占用槽位，迟到结果不能把状态改为可用。服务失联、关闭语音或更换声线会使相应就绪状态失效。

## Windows 本地运维

机器人保持 Python 3.13，TTS 使用独立 Python 3.10 CPU 环境。上游、声线和前置模型校验值见 [语音锁文件](../config/speech-upstream-lock.json)，直接依赖见 [语音依赖](../config/speech-requirements.txt)，完整版本锁见 [CPU 环境锁](../config/speech-requirements.lock.txt)。

默认目录：`downloads/GPT-SoVITS-cpu` 为原始上游源，`data/tts` 为运行时、模型、配置和日志，`data/personas/voices.json` 为本地声线档案。所有这些本机数据均不进入公开源码。准备声线权重、参考音频与台词，以及上游要求的 BERT、HuBERT、G2PW、语言识别和说话人编码器。

```powershell
.\.venv\Scripts\python.exe scripts/install_speech.py
.\.venv\Scripts\python.exe scripts/install_speech.py --verify
.\.venv\Scripts\python.exe scripts/configure_speech.py
.\scripts\start_speech.ps1
.\.venv\Scripts\python.exe scripts/probe_speech.py
.\.venv\Scripts\python.exe scripts/probe_speech.py --readiness-only
```

配置脚本支持自定义模型及 `--persona tangtang`，不改聊天模型或 `.env`。NoneBot 的语音后台负责有限重试。总开关关闭后禁止后续发送，不强杀底层合成。验收脚本只生成本地 WAV 和耗时报告，不发 QQ 消息；性能不达标时暂停语音上线，不自动改用云服务或其他操作系统。

安装器需要 PATH 中已有 ffmpeg；默认只补齐缺失文件，发现已有文件与锁定校验值不同会停止，不覆盖。`--verify` 只读核验源码和模型。g2pW 发音缓存通过进程内兼容层写入 `data/tts/g2pw-cache`，不写回上游文件。糖糖绑定必须显式传入声线 ID、两个权重、参考音频及台词，避免误用达妮娅默认值。

维护时先关闭语音总开关，再执行 `scripts/stop_speech.ps1` 停止独立服务，避免后台自动拉起。不要停止 QQ 或 SnowLuma。

专用快捷入口为 [启动语音](../启动工具/12-启动语音.bat) 和 [关闭语音](../启动工具/13-关闭语音.bat)。启动入口显式开启总开关，关闭入口先关闭总开关再停止模型进程（包括 Windows Python 启动器的子进程），均保留各群设置。日常启动全部会一起启动已配置且开启的语音服务；关闭全部只停进程，保留开关，下次恢复。关闭过的总开关不会被日常启动覆盖。

语音健康检查独立于话题与成长整理，每 10 秒执行；异常退出后后台以至少 120 秒间隔尝试拉起，实际预热成功才可用。`data/tts/readiness.json` 记录最近检查时间、进程与就绪状态，仅为本机诊断信息，过期记录不代表当前健康。模型会常驻内存，点击关闭语音可释放资源。语音故障只使聊天回退文字，不阻塞其他功能启动。

主动要求语音仍需要先取得聊天模型的有效回答和同意。聊天模型超时不会进入合成，也不等于人格拒绝或语音故障；可通过聊天用量日志、语音送达记录和就绪状态区分。

## 素材与后台预算

固定来源为鸣潮官网新闻索引和现有枝江日历。保存来源、日期、抓取时间和摘要；只在已有回复机会注入一个相关话题，不定时发消息。默认不附链接，追问时提供最近素材的准确链接。缺少有效资料时安排刷新并承认信息不足，不把网页当成指令或永久知识。

每六小时检查素材，无启用聊天的群时不工作。成长至少积累五次新送达互动后处理：后台单并发、每日全局最多 12 次模型调用、每群最多 2 次（两人格合计），输入最多 8,000 字符、输出最多 800 tokens、超时 30 秒。固定索引和日历采用确定性整理，不另调用摘要模型。额度耗尽安静暂停，状态显示原因，不借用聊天额度。
