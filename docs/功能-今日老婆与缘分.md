# 功能：今日老婆与缘分

独立群内社交功能，默认在全部受管群启用；不受小游戏开关和直播暂停影响。玩家只负责领取关系，后续互动与三幕故事由糖糖在后台自动演算。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `#今日老婆` / `#今日缘分` | 每人每天随机抽取一位当前群成员；重复发送只查看当天结果。 |
| `#强取 @群友` | 定向抽取指定群友；已有当天老婆时失败。 |
| `#离婚` / `#解缘` | 结束当前关系；当日可再抽取一次，第二次解缘后不能再抽。 |
| `#我的缘分` / `#我的老婆` | 查看今天主线、被谁写进故事、好感与互动镜头，可翻页。 |
| `#群缘分` / `#群老婆` | 查看当天关系图，可加 `历史` 或 `YYYY-MM-DD`。 |
| `#清缘`，60 秒内 `#确认清缘` / `#取消清缘` | 仅超级管理员清理当前群关系记录，保留近三天匿名活跃计数。 |

## 行为规则

也可以呼叫当前人格说“看看我今天的缘分”或“看看本群缘分”。聊天技能复用 `#我的缘分`／`#群缘分` 的当前图片，只查询已有关系，不触发抽取、离婚、清空或额外随机互动。历史分页和指定日期仍使用直接指令。

- 仅最近三天内有发言的群成员进入候选池；抽取为加权随机，当天被抽中者快速降权，双向关系获得戏剧性提升。
- 每天先等概率抽取现实日常、轻奇幻或强幻想主题之一，主题改变回应、助攻、误会修复和第三方扩散的倾向。
- 靠近/倾听、回应、修复和助攻仍遵守原有关系前置条件，但玩家不能主动选择。非首位参与者执行玩法命令时，有概率静默触发一位其他参与者的有效互动。
- 每天 11:30-12:00、17:30-18:00、23:00-23:30 进行三轮集体互动。有效群在各窗口内错开发送长图；每位当前有效关系的主动领取者都会执行一次互动。
- 第一轮结束进入第二幕，第二轮结束进入第三幕，第三轮抽选核心事件后立即收官封场。每轮长图先列核心和代表事件，再列该轮其余全部事件。
- 静默互动只在 `#我的缘分` 的个人镜头和 `#群缘分` 的当前关系效果中体现；离婚关系以灰色虚线和“曾经好感”保留在群像。
- 今日老婆网页玩法、`/wife/*` 公网路由和专属隧道已经移除。
