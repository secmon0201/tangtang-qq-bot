# 功能：今日老婆与缘分

独立群内社交功能，默认在全部受管群启用；不受小游戏开关和直播暂停影响。每天随机抽取对象并生成缘分故事，成员可以通过互动共同塑造当天群像。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `#今日老婆` / `#今日缘分` | 每人每天随机抽取一位当前群成员；重复发送只查看当天结果。 |
| `#强取 @群友` | 定向抽取指定群友；已有当天老婆时失败。 |
| `#互动 靠近/倾听/回应/修复/助攻 [@群友]` | 参与当天群像；每人每天最多 5 次。 |
| `#离婚` / `#解缘` | 结束当前关系；当日可再抽取一次，第二次解缘后不能再抽。 |
| `#我的缘分` / `#我的老婆` | 查看今天主线、被谁写进故事、好感与互动镜头，可翻页。 |
| `#群缘分` / `#群老婆` | 查看当天关系图，可加 `历史` 或 `YYYY-MM-DD`。 |
| `#清缘`，60 秒内 `#确认清缘` / `#取消清缘` | 仅超级管理员清理当前群关系记录，保留近三天匿名活跃计数。 |

## 行为规则

- 仅最近三天内有发言的群成员进入候选池；抽取为加权随机，当天被抽中者快速降权，双向关系获得戏剧性提升。
- 每天先等概率抽取现实日常、轻奇幻或强幻想主题之一，主题改变回应、助攻、误会修复和第三方扩散的倾向。
- 靠近/倾听作用于自己的关系，回应作用于指向自己的关系，修复承接负向关系，助攻只带来正向影响；好感可为负数，负向关系由当事人修复时挽救概率更高。
- 每天 23:50 起封场，抽取、离婚和互动停止；23:50-23:59 发送一次自适应终章。
- 互动公开展示剧情与数值影响，完整进展归入个人缘分和群缘分；离婚关系以灰色虚线和“曾经好感”保留在群像。
