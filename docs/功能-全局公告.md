# 功能：全局公告

超级管理员向固定五个 A 海岸群发送文字通告图片或图片公告，可选 @ 全体。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `#全局通告 [@全体] [人物] <内容>` | 渲染为图片后发送到全部 A 海岸群；可选人物表情包（嘉然/乃琳/贝拉/心宜/思诺），省略时随机。 |
| `#全局图片公告 [@全体]` / `#图片公告 [@全体]` | 回复一张图片后使用，或指令与图片放同一条消息；只取第一张图片。 |

## 行为规则

- 仅超级管理员可用；目标固定为五个 A 海岸群，不接受任意群号。
- 默认不 @ 全体；显式加入 `@全体` 或 `@all` 才提醒全体成员，权限不足时自动回退普通消息。
- 图片公告直接转发原图段，不下载重渲染；发送失败会逐群记录，不把失败当作成功。

## 维护与验证

目标固定、超管权限和图片转发见 `tests/test_global_announcement.py`。
