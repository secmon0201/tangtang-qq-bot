# 功能：全局公告

向选定的独群、集群或集群成员群发送文字海报、图文海报或原图公告。超级管理员始终可用；公告专用名单成员只获得本功能的发送权限。

## 使用前配置

在 `.env` 中填写公告专用名单，多个 QQ 号用英文逗号分隔：

```dotenv
GLOBAL_ANNOUNCEMENT_OPERATOR_IDS=123456,234567
```

- 留空时，只有 `BOT_OPERATOR_IDS` 中的超级管理员能发送公告。
- 名单成员可使用本页的三条公告命令，但不会获得查重、白名单、集群维护、系统设置或其他超级管理员权限。
- QQ 号会去重；只允许填写大于零的数字。修改 `.env` 后，运行配置校验并只重启 NoneBot 才会生效。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `#全局通告 [@全体] [人物] <内容>` | 渲染为图片后发送到全部固定目标群；可选人物表情包（嘉然/乃琳/贝拉/心宜/思诺），省略时随机。 |
| `#全局图片公告 [@全体]` / `#图片公告 [@全体]` | 回复一张图片后使用，或指令与图片放同一条消息；只取第一张图片。 |
| `#公告网页` / `#公告面板` | 创建一条 15 分钟有效、一次性使用的公告编辑页链接。 |

## 公告网页

公告专用名单成员或超级管理员可私聊机器人发送 `#公告网页`，也可在受管群发送。网页链接只授予本次操作能力，不显示或接受 QQ 号、群号和其他管理功能。

页面先显示多选目标树：独群、集群和集群成员都可同时选择，重复命中的群号自动去重；“全选”可满足全部群发送。会话创建时冻结可选目标快照，预览和最终发送使用同一目标集合。

页面有三个模式：

- **文字海报**：填写正文，点选或随机角色，再点选或随机该角色表情；网页只接收低码率预览，机器人本机保留完整 PNG，确认后发送完整海报。
- **原图公告**：选择一张 PNG、JPG、JPEG、GIF 或 WebP 图片，最大 20 MiB；选择时不上传、不生成预览，确认后才一次上传原文件并直接发送，不叠加角色或文字。
- **图文海报**：上传一张 PNG、JPG、JPEG 或 WebP 主图，填写标题和正文，再选择角色、随机角色或无角色；网页只接收低码率预览，机器人本机保留完整 PNG 用于确认发送。主图会按海报固定宽度等比缩放并左右铺满，不裁切；海报高度随主图和正文动态增加，四角圆角外保持透明。角色贴纸位于独立底部留白区，与正文和卡片边框保留固定间距。动图请改用原图公告。

三种模式都可填写最多 1000 字的附加文字。留空时仍只发送图片；填写后，图片和附加文字会作为同一条 QQ 消息发出，顺序为图片、换行、文字。附加文字不写入海报预览。

`@全体` 使用网页开关控制。点击生成预览后，按钮和预览区会立即显示生成中状态，完成后才显示可发送的预览。原图公告会显示上传百分比，上传完成后显示发送状态。提交前会明确显示去重后的目标群数量；提交后显示成功和失败群数。链接过期、已提交或发送中时不能再次提交，重新发送 `#公告网页` 获取新链接。

固定域名模式使用 `https://tangtang.secmon.cn/notice/<令牌>`；统一公网网关只把 `/notice/*` 映射到本功能的 `/announcement/*`，权限与会话仍由公告插件独立处理。域名生效前可继续使用独立 Quick Tunnel：

```powershell
.\启动工具\24-启动公告网页隧道.bat
.\启动工具\25-关闭公告网页隧道.bat
```

启动后，`#公告网页` 才会返回可供群友打开的链接。临时隧道只放行 `/notice/*`（兼容旧 `/announcement/*`）到本机 NoneBot；固定网关同样不暴露 `/ws/*`、`/api/*` 或其他内部路由。统一地址规划见 [网页地址与固定隧道](运维-网页地址与固定隧道.md)。

## 发送流程

### 文字通告

直接发送 `#全局通告` 和内容，例如：

```text
#全局通告 心宜 今晚八点一起看直播
#全局通告 @全体 嘉然 今晚八点一起看直播
```

- 可选人物为嘉然、乃琳、贝拉、心宜、思诺；省略时随机选用。
- 人物后还可填写该人物可用的表情包名；无法匹配时仍会使用该人物的可用表情包。
- 内容最多 1000 个字符，保留换行并渲染为公告图片。

### 图片公告

在一张图片上回复 `#全局图片公告` 或 `#图片公告`；也可以把命令和图片放在同一条消息中。需要提醒全体成员时，在命令文本中加入 `@全体` 或 `@all`：

```text
#图片公告 @全体
```

只会发送第一张图片，直接转发原始 OneBot 图片段，不下载或重渲染图片。

## 行为规则

- 仅超级管理员或 `GLOBAL_ANNOUNCEMENT_OPERATOR_IDS` 名单成员可用；网页目标只能从签发时的独群、集群和成员群快照中选择，不接受任意群号。
- 默认不 @ 全体；显式加入 `@全体` 或 `@all` 才提醒全体成员，权限不足时自动回退普通消息。
- 目标群必须位于机器人管理范围内；不在管理范围内的目标群会被跳过，并写入启动或运行日志。
- 发送完成会返回成功群数；存在失败时会明确显示失败群数。失败不会被当作发送成功，可稍后重试。

## 维护与验证

配置完成后执行：

```powershell
.\.venv\Scripts\python.exe scripts\validate_qq_config.py --env .env
.\scripts\stop.ps1
.\scripts\start.ps1
```

只重启 NoneBot，不重启 SnowLuma 或 QQ。目标快照、多选去重、公告权限和图片转发由 `tests/test_global_announcement.py` 保护。

### 本地图片输出样式

机器人本地确定性生成的公告、报告、卡片、排行和帮助图统一保存为 PNG，并使用透明圆角：圆角以内完整显示，四角以外透明。用户上传的原图公告、头像缓存和外部来源图片不做重绘。
