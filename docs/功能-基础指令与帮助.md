# 功能：基础指令与帮助

所有角色的统一入口和运行状态查询。群内与私聊命令统一使用 `#` 前缀，不需要 @ 机器人；普通成员、本群机器人管理员和超级管理员使用同一格式，再由各命令检查权限。

## 可用范围

`#帮助` 和 `#帮助文字` 面向受管群；在线帮助会展示普通群友入口，以及本群群主、QQ 群管理员可维护的当前群设置。`#机器人状态`、`#管理员帮助` / `#超级管理员帮助` 仅 `BOT_OPERATOR_IDS` 中的超级管理员可用。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `#帮助` | 返回 `帮助在线：short.example.invalid/h`，打开可切换、可复制指令并带有在线快捷入口的公开帮助页。 |
| `#帮助文字` | 以合并转发返回可复制的公开入口文字，避免刷屏。 |
| `#机器人状态` | 超级管理员查看机器人、功能范围和运行状态。 |
| `#管理员帮助` / `#超级管理员帮助` | 查看超级管理员指令帮助。 |

完整命令、参数和别名以 [全部 `#` 指令清单](全部#指令清单.md) 为准。

## 行为规则

- 在线帮助只展示普通群友能力和本群管理员的当前群设置入口，不展示集群维护、公告面板、查重、活动/问卷旧能力或高权限管理命令。
- 发言排行链接由对应群域的主动查询或 23:50 推送附带，帮助页不提供可绕过令牌的固定排行入口。
- 超级管理员帮助图片会动态显示实际登记群数量、群域命令和本地维护边界；不显示 OneBot Token、AI API Key、QQ 密码或其他凭据。
- 群内普通非命令消息不会触发本功能；命令响应受 [响应延迟与平台节流](运维-安装与运行.md) 约束。

## 配置

- `BOT_COMMAND_PREFIX=#`、`BOT_REQUIRE_MENTION=false`：统一前缀和是否需要 @。
- `BOT_RESPONSE_DELAY_MIN_SECONDS` / `BOT_RESPONSE_DELAY_MAX_SECONDS`：普通互动发送延迟，允许设为 0；例如 `0` / `0.5` 表示发送前随机等待 0～0.5 秒。修改后需仅重启机器人，不影响呼叫消息合并窗口。
- `BOT_COMMAND_RESPONSE_DELAY_MIN_SECONDS` / `BOT_COMMAND_RESPONSE_DELAY_MAX_SECONDS`：`#` 指令反馈延迟。

角色与身份定义见 [权限与范围](功能-权限与范围.md)。
