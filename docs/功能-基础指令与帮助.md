# 功能：基础指令与帮助

所有角色的统一入口和运行状态查询。群内与私聊命令统一使用 `#` 前缀，不需要 @ 机器人，普通用户、活动管理员和超级管理员使用同一格式，再由各命令检查权限。

## 可用范围

`#帮助`、`#帮助文字` 和 `#机器人状态` 面向受管群；`#管理员帮助` / `#超级管理员帮助` 仅 `BOT_OPERATOR_IDS` 中的超级管理员可用。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `#帮助` | 返回 `帮助在线：s.secmon.cn/h`，打开可切换、可复制指令并带有在线快捷入口的普通用户帮助页。 |
| `#帮助文字` | 以合并转发返回可复制的纯指令文字，避免刷屏。 |
| `#机器人状态` | 查看机器人、功能范围和运行状态。 |
| `#管理员帮助` / `#超级管理员帮助` | 查看超级管理员指令帮助。 |

完整命令、参数和别名以 [全部 `#` 指令清单](全部#指令清单.md) 为准。

## 行为规则

- 在线帮助完整保留原普通用户帮助文案，不展示高权限管理命令；本地小游戏及其榜单在网页中合并为一个大类，直播日程与 A海岸发言排行提供已登记的网页快捷入口。
- `#活动帮助`、`#活动管理员帮助` 分别见 [跨群活动](功能-跨群活动.md)。
- 超级管理员帮助图片会动态显示管理员名单、管理群数量、各功能范围和本地维护命令；不显示 OneBot Token、AI API Key、QQ 密码或其他凭据。
- 群内普通非命令消息不会触发本功能；命令响应受 [响应延迟与平台节流](运维-安装与运行.md) 约束。

## 配置

- `BOT_COMMAND_PREFIX=#`、`BOT_REQUIRE_MENTION=false`：统一前缀和是否需要 @。
- `BOT_RESPONSE_DELAY_MIN_SECONDS` / `BOT_RESPONSE_DELAY_MAX_SECONDS`：普通互动发送延迟。
- `BOT_COMMAND_RESPONSE_DELAY_MIN_SECONDS` / `BOT_COMMAND_RESPONSE_DELAY_MAX_SECONDS`：`#` 指令反馈延迟。

角色与身份定义见 [权限与范围](功能-权限与范围.md)。
