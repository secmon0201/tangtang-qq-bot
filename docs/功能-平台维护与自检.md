# 功能：平台维护与自检

NapCat 连接维护记录和 QQ 平台能力自检。维护任务默认每 30 秒检查一次 OneBot 反向 WebSocket，把“已连接后断开”的时间、QQ.exe 进程快照和恢复耗时写入 SQLite；不绕过 QQ 登录验证，不保存 OneBot Token 或 NapCat 日志原文。

## 常用命令（仅超级管理员）

| 命令 | 说明 |
| --- | --- |
| `#QQ平台自检` | 检查当前 OneBot / NapCat 平台能力。 |
| `#NapCat维护状态` | 查看本地维护进程、当前 OneBot 连接和未恢复的断线事件；不显示令牌或配置内容。 |
| `#NapCat离线记录 [1-20]` | 查看最近被动断线记录、QQ 进程快照、触发来源和恢复耗时。 |

## 配置

- `NAPCAT_MAINTENANCE_ENABLED`、`NAPCAT_MAINTENANCE_INTERVAL_SECONDS`：维护任务开关与检查间隔。

## 维护与验证

断线记录、恢复耗时和平台能力探测见 `tests/test_napcat_maintenance.py`、`tests/test_qq_platform.py`。watchdog 守护行为见 [安装与运行](运维-安装与运行.md)。
