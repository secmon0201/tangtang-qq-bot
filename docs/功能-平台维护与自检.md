# 功能：平台维护与自检

QQ 传输连接维护记录和平台能力自检。维护任务默认每 30 秒检查一次 OneBot 反向 WebSocket，把“已连接后断开”的时间、QQ.exe 进程快照和恢复耗时写入 SQLite；不绕过 QQ 登录验证，不保存 OneBot Token 或 SnowLuma 日志原文。

## 常用命令（仅超级管理员）

| 命令 | 说明 |
| --- | --- |
| `#QQ平台自检` | 检查当前 OneBot / SnowLuma 平台的登录信息、当前群资料与成员列表。 |
| `#QQ传输维护状态` | 查看传输类型、当前 OneBot 连接和未恢复的断线事件；不显示令牌或配置内容。 |
| `#QQ传输离线记录 [1-20]` | 查看最近被动断线记录、QQ 进程快照、触发来源和恢复耗时。 |

## 配置

- `QQ_PLATFORM_TRANSPORT`：当前个人 QQ 网关，生产值为 `snowluma`。
- `QQ_TRANSPORT_MAINTENANCE_ENABLED`、`QQ_TRANSPORT_MAINTENANCE_INTERVAL_SECONDS`：维护任务开关与检查间隔。

旧数据库中的 NapCat 断线表会在首次启动新版机器人时无损迁移到 `qq_transport_connection_incidents`，随后删除旧表；事件内容、时间和恢复耗时保持不变。

## 维护与验证

断线记录、恢复耗时和平台能力探测见 `tests/test_qq_transport_maintenance.py`、`tests/test_qq_platform.py`。watchdog 守护行为见 [安装与运行](运维-安装与运行.md)。
