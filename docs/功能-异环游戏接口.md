# 功能：异环游戏接口

启用的游戏生态之一：本地 GsUID Core 承载异环 NTEUID。链路为 `SnowLuma -> OneBot v11 -> NoneBot2 -> GenshinUID 连接器 -> GsUID.Core:8765 -> NTEUID`。鸣潮使用独立的 `ww` 接口，原神保持关闭。

## 运行边界

- 识别 `nte` 前缀，可带或不带 `#`，大小写不敏感；`ww` 由独立鸣潮接口处理，`gs/ys/yh/gsuid` 一律不响应。
- 新独群默认开启 NTE；本群群主、群管理员或超级管理员可用 `#群设置 NTE 开|关` 修改。关闭只阻止该群成员主动触发 NTE，不修改或剔除上游已有记录。
- 机器人级运行条件由超级管理员私聊 `#系统设置 游戏接口 状态|开|关` 维护，并与鸣潮共用；SQLite 保存两个独立群开关，`.env` 群列表只作迁移种子。
- 独立于本地小游戏：不受小游戏范围、总开关和枝江直播守卫影响。
- `#nte帮助`、四个糖糖定制排行和帮助图由本项目 `bot/plugins/nte_game_ui.py` 接管；其余命令和单张“角色最强面板”继续走上游 NTEUID。
- 排行榜只读 `GsUID.Core\data\GsData.db`，按 `ntegroupmember.bot_id=onebot` 过滤；不修改 Core 代码、配置、数据和素材。
- 接管只在 NoneBot 消息入口匹配并截断本地白名单命令；未匹配消息原样继续发送上游。本地渲染可以加工只读结果和资源，不替换 NTEUID 内部实现。
- Core 不可用时，连接器在普通消息路径立即跳过转发，NoneBot 启动也不等待连接；single-flight 定时任务默认每 10 秒在后台重连。因此 GsUID 故障不会阻塞 `#今日直播` 等无关本地命令。

## 常用命令

登录与账号：`#nte登录`、`#nte查看`、`#nte刷新令牌`、`#nte退出登录`、`#nte全部登出`。

查询与图片：`#nte帮助`、`#nte原版帮助`、`#nte查询`、`#nte角色`、`#nte刷新面板`、`#nte角色练度`、`#nte实时信息`、`#nte成就`、`#nte房产`、`#nte载具`、`#nte探索`。

排行榜：`#nte薄荷排行`、`#nte薄荷总排行`、`#nte最强排行`、`#nte最强总排行`。不写“总”的命令默认只看当前群；只有显式“总排行”才看机器人记录到的全部群。`bot` 与旧“群”范围写法仅作兼容，不在普通帮助中推广。跨群总榜取 `updated_at` 最新行，本人不在当前页时附真实名次。

攻略与公告：`#nte角色列表`、`#nte早雾配队`、`#nte早雾攻略`、`#nte早雾图鉴`、`#nte公告`、`#nte签到日历`、`#nte签到`。账号绑定列表是 `#nte查看`，`#nte绑定` 不是可执行命令。

完整命令以 `#nte帮助` 返回的本地帮助图为准。

## 排行与帮助接管规则

- 排行榜数据通过 SQLite 只读 URI 读取；排序为评分降序、评级 S/A/B、最近更新群号、UID。
- NTE 机器人总榜是独群模式下唯一允许查看其他群记录的排行榜；本地小游戏和发言榜不会扩展到机器人全局。
- 所属群取账号最近一次 `#nte刷新面板` 所在群；同时间取较小群号；固定群别名优先于实时群名。
- 角色原图按数据库出现的角色 ID 通用刷新，失败时保留最后一张有效缓存，不做错误角色替换。
- 上游帮助快照由 `scripts/export_nte_original_help.py` 生成到 `data/nte_original_help.png`，不进入 Git。

## 公网登录地址

`#nte登录` 的链接由 `NTELoginUrl` 决定；Core 只监听 `127.0.0.1` 时链接是 localhost，只有本机能打开。需要群友登录时使用快速隧道：

- `启动工具\21-启动异环登录隧道.bat`：启动或刷新，每次地址都会变，脚本会写回 `NTELoginUrl` 并重启 Core。
- `启动工具\22-关闭异环登录隧道.bat`：关闭并写入禁用标记，watchdog 不会自动拉起。
- `启动工具\23-设置异环登录地址.bat`：手动写入已有 HTTPS 地址。

cloudflared 指向本地 `127.0.0.1:18765` 受限代理（`scripts/nte_login_proxy.py`），只放行 `/nte/i/*`、`/nte/done`、`/nte/sendSmsCode`、`/nte/login`、`/nte/status/*`，其余路径 404；Core 的 `/ws/*` 和 `/api/*` 不暴露。

固定模式使用 `https://bot.example.invalid/nte/*`。同一域名的根路径是糖糖主页，统一网关只将 `/nte/*` 转发到 Core，其他机器人网页继续走各自路径；配置、启停和验收见 [网页地址与固定隧道](运维-网页地址与固定隧道.md)。

## 安装与更新

首次安装或更新：先停止 Core，再运行 `scripts\install_gsuid.ps1`。仓库列表来自 `config/upstream-lock.json`；脚本会修复声明分支的 tracking 并且只做 fast-forward。已跟踪/未跟踪改动、stash、本地独有提交和分叉都会直接停止；不要强制覆盖或 stash 后继续，应把必要适配迁回 `bot/integrations` 或 `bot/services`。更新后：

```powershell
.\.venv\Scripts\python.exe scripts\validate_upstream_lock.py
.\.venv\Scripts\python.exe scripts\validate_nte_mode.py
.\.venv\Scripts\python.exe -m pytest tests\test_game_api.py tests\test_nte_rank.py tests\test_nte_prefix_display.py tests\test_gsuid_core_compat.py tests\test_genshinuid_connector_compat.py
```

启动顺序固定为 Core → NoneBot → SnowLuma；关闭顺序相反。具体步骤见 [安装与运行](运维-安装与运行.md)。

## 测试

- 独立第二实例冒烟测试：`scripts\smoke_game_api.py --server` 与 `--client`，使用 18081 端口和临时数据库，不会断开 SnowLuma/QQ。
- 旧脚本 `scripts\smoke_test_gsuid.py` 会占用同一个 OneBot `self_id`，运行前需暂时关闭 SnowLuma WebSocket 客户端。
- 未配置群不响应：用 `SMOKE_GROUP_ID` 环境变量指定虚拟群号，预期 `PASS_NO_OUTPUT`。

## AI 与 Token

当前 Core 的 AI 总开关关闭，不调用互联网大模型；排行榜、帮助图等由本项目本地渲染。游戏查询访问上游普通数据服务、图片 CDN 和登录服务，消耗网络流量但不产生大模型 Token 费用。
