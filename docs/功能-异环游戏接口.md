# 功能：异环游戏接口

唯一启用的游戏生态：本地 GsUID Core 承载异环 NTEUID。链路为 `NapCat -> OneBot v11 -> NoneBot2 -> GenshinUID 连接器 -> GsUID.Core:8765 -> NTEUID`。原神和鸣潮保持关闭。

## 运行边界

- 识别 `nte` 前缀，可带或不带 `#`，大小写不敏感；`gs/ww/yh` 一律不响应。
- 范围默认全部 `MANAGED_GROUP_IDS`，可用 `#功能范围 游戏接口 添加/移除` 单独控制并实时写回 `GAME_API_GROUP_IDS`；热开关 `#游戏接口 状态/开启/关闭` 写回 `GAME_API_ENABLED`。
- 独立于本地小游戏：不受小游戏范围、总开关和枝江直播守卫影响。
- `#nte帮助`、四个糖糖定制排行和帮助图由本项目 `bot/plugins/nte_game_ui.py` 接管；其余命令和单张“角色最强面板”继续走上游 NTEUID。
- 排行榜只读 `GsUID.Core\data\GsData.db`，按 `ntegroupmember.bot_id=onebot` 过滤；不修改 Core 代码、配置、数据和素材。

## 常用命令

登录与账号：`#nte登录`、`#nte查看`、`#nte刷新令牌`、`#nte退出登录`、`#nte全部登出`。

查询与图片：`#nte帮助`、`#nte原版帮助`、`#nte查询`、`#nte角色`、`#nte刷新面板`、`#nte角色练度`、`#nte实时信息`、`#nte成就`、`#nte房产`、`#nte载具`、`#nte探索`。

排行榜：`#nte薄荷排行`、`#nte薄荷群排行`、`#nte最强排行`、`#nte群最强排行`。默认分流为 A 海岸五群内看五群总榜、其他管理群看 bot 全榜，加 `群` 看本群；跨群榜取 `updated_at` 最新行，本人不在当前页时附真实名次。

攻略与公告：`#nte角色列表`、`#nte早雾配队`、`#nte早雾攻略`、`#nte早雾图鉴`、`#nte公告`、`#nte签到日历`、`#nte签到`。账号绑定列表是 `#nte查看`，`#nte绑定` 不是可执行命令。

完整命令以 `#nte帮助` 返回的本地帮助图为准。

## 排行与帮助接管规则

- 排行榜数据通过 SQLite 只读 URI 读取；排序为评分降序、评级 S/A/B、最近更新群号、UID。
- 所属群取账号最近一次 `#nte刷新面板` 所在群；同时间取较小群号；固定群别名优先于实时群名。
- 角色原图按数据库出现的角色 ID 通用刷新，失败时保留最后一张有效缓存，不做错误角色替换。
- 上游帮助快照由 `scripts/export_nte_original_help.py` 生成到 `data/nte_original_help.png`，不进入 Git。

## 公网登录地址

`#nte登录` 的链接由 `NTELoginUrl` 决定；Core 只监听 `127.0.0.1` 时链接是 localhost，只有本机能打开。需要群友登录时使用快速隧道：

- `启动工具\21-启动异环登录隧道.bat`：启动或刷新，每次地址都会变，脚本会写回 `NTELoginUrl` 并重启 Core。
- `启动工具\22-关闭异环登录隧道.bat`：关闭并写入禁用标记，watchdog 不会自动拉起。
- `启动工具\23-设置异环登录地址.bat`：手动写入已有 HTTPS 地址。

cloudflared 指向本地 `127.0.0.1:18765` 受限代理（`scripts/nte_login_proxy.py`），只放行 `/nte/i/*`、`/nte/done`、`/nte/sendSmsCode`、`/nte/login`、`/nte/status/*`，其余路径 404；Core 的 `/ws/*` 和 `/api/*` 不暴露。

## 安装与更新

首次安装或更新：先停止 Core，再运行 `scripts\install_gsuid.ps1`。脚本发现上游仓库有本地改动会直接停止；不要 stash 后继续更新，应把必要适配迁回 `bot/integrations` 或 `bot/services`。更新后：

```powershell
.\.venv\Scripts\python.exe scripts\validate_upstream_lock.py
.\.venv\Scripts\python.exe scripts\validate_nte_mode.py
.\.venv\Scripts\python.exe -m pytest tests\test_game_api.py tests\test_nte_rank.py tests\test_nte_prefix_display.py tests\test_gsuid_core_compat.py
```

启动顺序固定为 Core → NoneBot → NapCat；关闭顺序相反。具体步骤见 [安装与运行](运维-安装与运行.md)。

## 测试

- 独立第二实例冒烟测试：`scripts\smoke_game_api.py --server` 与 `--client`，使用 18081 端口和临时数据库，不会断开 NapCat/QQ。
- 旧脚本 `scripts\smoke_test_gsuid.py` 会占用同一个 OneBot `self_id`，运行前需暂时关闭 NapCat WebSocket 客户端。
- 未配置群不响应：用 `SMOKE_GROUP_ID` 环境变量指定虚拟群号，预期 `PASS_NO_OUTPUT`。

## AI 与 Token

当前 Core 的 AI 总开关关闭，不调用互联网大模型；排行榜、帮助图等由本项目本地渲染。游戏查询访问上游普通数据服务、图片 CDN 和登录服务，消耗网络流量但不产生大模型 Token 费用。
