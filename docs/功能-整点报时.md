# 功能：整点报时

在指定时段向指定群发送一条本地组合的枝江风格整点文案，默认关闭。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `#整点报时 状态` / `#整点报时 开启` / `#整点报时 关闭` | 查看或切换全局启停。 |
| `#整点报时 时段 <HH:MM> <HH:MM>` | 设置发送时段，支持跨午夜，例如 `22:00 02:00`。 |
| `#整点报时 范围 添加/移除/列表` | 维护发送群范围，也可用 `#功能范围 整点报时`。 |

完整命令见 [全部 `#` 指令清单](全部#指令清单.md)。

## 行为规则

- 每个群每个整点最多发送一条；发送失败只在整点后 5 分钟内有限重试，最多 3 次，重启不重复发送已成功的整点。
- 文案由 `bot/resources/zhijiang_hourly_copy.json` 的四个时段（前/中/后三段，每段至少 100 条）和 `bot/resources/zhijiang_character_aliases.json` 的分类花名实时随机组合；纯文案理论组合由 `scripts/generate_hourly_copy.py` 校验。
- 花名按 `asoul` 与 `other` 分类，分段可通过 `name_categories` 选择可用范围；`other` 包含鸣潮角色、群聊中性称呼和枝江公共意象。
- 糖糖聊天记录库中的真实用户原话不进入文案池，只抽象公共口头禅和节奏。
- 启停、时段和群范围热更新并永久保存到 SQLite；文案池修改后需重启机器人重新加载。

## 配置

- `HOURLY_ANNOUNCEMENT_ENABLED`、`HOURLY_ANNOUNCEMENT_GROUP_IDS`：初始开关与群范围，运行中以 SQLite 为准。
- `HOURLY_ANNOUNCEMENT_START` / `HOURLY_ANNOUNCEMENT_END`：初始时段。
- `HOURLY_ANNOUNCEMENT_MAX_ATTEMPTS`：失败重试次数。
