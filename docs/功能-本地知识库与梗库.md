# 功能：本地知识库与梗库

枝江百科和鸣潮梗库统一存储在本地 SQLite，供糖糖预注入和工具检索；超级管理员通过审核命令维护词条。公开群聊没有 `#枝江百科` 查询命令，百科内容只作为糖糖的本地资料。

## 存储与审核

- 统一存储在 `data/knowledge/knowledge.db` 的 `knowledge_entries` 表；`bot/resources/zhijiang_encyclopedia.json` 和 `mingchao_meme_culture.json` 只作为首次播种来源。
- 每条词条带 `status`（approved/pending）、`source_priority`、`updated_at`、`conflict_note`；糖糖预注入和查询工具只读 `approved` 词条。
- 事实类词条以枝江百科为主，梗文化词条以鸣潮梗库为主，通过 `related_ids` 交叉引用，不重复存储同一事实。
- 联网热更仲裁链：本地已审核 > 联网检索经人工审核 > 联网待审 > 模型内部知识；冲突写入 `conflict_note` 由管理员判断。

## 审核命令（仅超级管理员）

| 命令 | 说明 |
| --- | --- |
| `#收录待审` / `#收录待审列表` | 查看待审核队列。 |
| `#收录确认 <编号>` | 收录词条，即时对糖糖生效。 |
| `#收录拒绝 <编号>` | 归档拒绝；后续重复内容自动拒绝。 |
| `#收录恢复待审 <编号>` | 把归档拒绝的词条恢复到待审。 |

## 文件化审核（推荐）

`data/knowledge/` 下四份文档配合命令使用：`收录待审.md`、`收录确认.md`、`收录拒绝.md`、`收录拒绝归档.md`。启动时按“读取确认/拒绝 → 清空 → 对比待审 → 重写待审”处理；直接编辑归档文档不会生效，归档只是数据库镜像。

## 内容边界

- 只收录可追溯的公开时间线、角色公开介绍和明确标注为社群语境的词汇；不记录或推断中之人身份、隐私、争议的未经证实细节。
- 珈乐相关词条在库内标记为违禁品，保留供内部维护，但不会进入对外检索、糖糖提示词或检索建议；含违禁内容的提案直接拒绝。
- 行为规则类词条只描述应对口径：黑梗、李滇滇、毒唯/著名唯粉词义，以及《Quiet》《超级敏感》《除夕》《传说的世界》等现行版本参考。
