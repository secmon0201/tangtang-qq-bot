# 功能：群域权限与本群设置

糖糖面向不限数量的 QQ 群。机器人首次观察到新群消息或同步到新群时，会把该群自动登记为独群；A海岸五群是首个固定私有集群。独群之间默认没有跨群互动，集群成员群才共享当前集群的统计与群域玩法。

## 权限模型

- 普通成员：使用当前群已开启的功能。
- 本群机器人管理员：QQ 群主、QQ 群管理员，以及超级管理员。身份通过 OneBot 实时查询，不维护第二份群管理员名单。
- 超级管理员：`BOT_OPERATOR_IDS` 中的 QQ。只有超级管理员可以在私聊创建、邀请、移除、解散和查询集群，以及维护机器人级运行条件。
- 不设置“集群管理员”。加入集群即启用集群能力，但各成员群的普通功能开关仍由该群自己的管理员决定。

## 新独群默认值

| 功能 | 默认 |
| --- | --- |
| 发言榜查询、NTE、鸣潮、枝江日历、小游戏、今日老婆、被呼叫会话、发言档案、枝江直播防护 | 开 |
| 23:50 发言榜推送、被动互动、糖糖主动聊天、准时报点、B站推送 | 关 |

枝江直播防护是独立开关，但依赖小游戏：防护开、小游戏关时不会产生额外动作。活动和调查/问卷不在运行功能范围内，旧实现只保留于 Git 历史供后续重做参考。

加入集群时，当前所有群功能先设为开启。之后群管理员仍可逐项开关；关闭查询或推送不把该群从集群统计成员中剔除。移出集群后，该群恢复为独群。

## 本群命令

| 指令 | 权限 | 说明 |
| --- | --- | --- |
| `#群设置` / `#本群设置` | 所有人 | 查看当前群代称和功能状态；普通成员只看到已开启项。 |
| `#群设置 代称 <名称>` | 本群机器人管理员 | 修改当前群代称；超级管理员也可修改。 |
| `#群设置 <功能> 开\|关` | 本群机器人管理员 | 修改当前群开关。 |
| `#开关小游戏`、`#开关今日老婆`、`#开关准时报点` | 本群机器人管理员 | 直接切换对应功能。 |
| `#开关被呼叫会话`、`#开关被动互动`、`#开关B站推送`、`#开关NTE`、`#开关鸣潮` | 本群机器人管理员 | 直接切换对应功能。 |
| `#群设置 过滤 列表\|添加\|移除 [QQ号]` | 本群机器人管理员 | 维护只作用于当前群的过滤名单。 |

## 系统命令

`#系统设置` 只接受超级管理员私聊：

- `#系统设置 集群 列表`
- `#系统设置 集群 创建 <名称>`
- `#系统设置 集群 邀请 <集群ID> <群号>`
- `#系统设置 集群 移除 <群号>`
- `#系统设置 集群 解散 <集群ID>`
- `#系统设置 游戏接口 状态|开|关`（NTE/鸣潮共用全局运行条件）
- `#系统设置 小游戏 全局 状态|开|关`
- `#系统设置 被呼叫会话 状态|开|关`
- `#系统设置 糖糖主动聊天 状态|开|关`
- `#系统设置 小游戏 禁言 <群号> 状态|开|关`
- `#系统设置 被动互动 <群号> 状态|<参数> <值>`
- `#系统设置 准时报点 状态|开|关|时段 HH:MM HH:MM`

被呼叫会话和糖糖主动聊天都是高 Token 消耗能力，实际生效必须同时满足机器人级总控和当前群开关均为开启。关闭系统总控不会覆盖各群保存的开关；重新开启后，各群按原状态恢复。`#群设置`中会把这种状态显示为“已配置开启，全局条件关闭”。

集群邀请只接受机器人当前实际加入且仍启用的群。成员变化、退群和解散都会轮换相关排行链接令牌，旧链接立即失效。

## 数据权威

- SQLite 是群登记、群域、代称、功能开关和过滤名单的运行权威。
- `MANAGED_GROUP_IDS` 等 `.env` 群列表只作为首次迁移种子；启动不会把 SQLite 中已禁用的群重新开启，也不会把群级设置反写到 `.env`。
- 机器人级参数、凭据和 OneBot 地址仍来自 `.env`；凭据不得进入群消息、文档或 Git。
- 群数量不设上限。状态卡显示当前实际登记数量，不再显示 `/10`。

完整命令见 [全部 `#` 指令清单](全部#指令清单.md)。
