# 功能：权限与范围

统一的三级角色模型、功能群范围维护和两类过滤名单。所有业务功能范围都必须是 `MANAGED_GROUP_IDS` 的子集。

## 角色模型

- 普通用户：默认权限，按具体命令判定。
- 活动管理员：`ACTIVITY_ADMIN_IDS` 中的 QQ，或活动有效群内的群主、群管理员；后者可被 `ACTIVITY_ADMIN_BLACKLIST_IDS` 排除。只能管理自己创建的活动。
- 超级管理员：`BOT_OPERATOR_IDS` 中的 QQ，管理全部活动、范围、白名单、过滤名单和系统状态。

私聊同样使用 `#` 前缀，权限不因私聊而绕过。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `#功能范围 [列表]` | 查看统计、查重、游戏、游戏接口、今日老婆、活动、被动互动、整点报时的群范围。 |
| `#功能范围 <类别> <添加/移除> <QQ群号>` | 热更指定功能的可用群；目标群必须先属于 `MANAGED_GROUP_IDS`。 |
| `#被动互动群 [列表/添加/移除]` | 专用维护被动互动群范围。 |
| `#主动过滤 <QQ号列表>` / `#移除主动过滤 <QQ号列表>` / `#主动过滤 列表` | 维护主动过滤名单。 |
| `#被动过滤 <QQ号列表>` / `#移除被动过滤 <QQ号列表>` / `#被动过滤 列表` | 维护被动过滤名单。 |
| `#运营网页` / `#运营面板` | 超级管理员获取一次性运营配置页，维护功能范围、被动互动参数与两类过滤名单。 |

完整列表见 [全部 `#` 指令清单](全部#指令清单.md)。

## 行为规则

`#运营网页` 只向超级管理员签发 15 分钟有效的能力链接。固定地址为 `https://tangtang.secmon.cn/operations/<令牌>`；页面保存操作仍调用原有 SQLite 与 `.env` 同步逻辑，范围只能选择 `MANAGED_GROUP_IDS` 内的群，不会展示或编辑账号令牌、登录态或其他运行维护设置。

- 范围是硬性开关：A海岸统计固定五群不可改；查重、本地小游戏、异环游戏接口、活动分别使用 `DUPLICATE_GROUP_IDS`、`GAME_GROUP_IDS`、`GAME_API_GROUP_IDS`、`ACTIVITY_GROUP_IDS`，不填写时按文档规则继承。
- 范围、过滤名单和被动互动参数写入 SQLite，热更新后重启仍保留；`#功能范围` 等命令还会实时写回 `.env` 对应键。
- 主动过滤：被过滤用户的所有 `#` 指令和小游戏操作静默无效；超级管理员自身的过滤管理命令仍可用，避免误加自己后无法恢复。
- 被动过滤：被过滤用户不触发随机表情、随机复读、三连复读、@ 自动表情，消息也不进入糖糖记忆。
- 两份名单独立保存，支持英文逗号、中文逗号或空格批量分隔。

## 配置

- `MANAGED_GROUP_IDS`：最高层管理范围，最多 10 个群；修改后需重启。
- `BOT_OPERATOR_IDS`、`ACTIVITY_ADMIN_IDS`、`ACTIVITY_ADMIN_BLACKLIST_IDS`：启动身份配置，修改后需重启。
- `GLOBAL_ANNOUNCEMENT_OPERATOR_IDS`：全局公告专用 QQ 名单；名单成员仅可使用全局通告和图片公告，不获得其他超级管理员权限，修改后需重启。
- `DUPLICATE_GROUP_IDS`、`GAME_GROUP_IDS`、`GAME_API_GROUP_IDS`、`ACTIVITY_GROUP_IDS`：各功能的初始范围。

## 维护与验证

范围与身份逻辑由 `tests/test_scope.py`、`tests/test_config.py` 保护。修改 `.env` 身份或范围后执行 `启动工具\11-仅重启机器人.bat`，只重启 NoneBot，不重启 NapCat/QQ。
