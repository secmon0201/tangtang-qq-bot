# 功能：枝江直播防护

按公开日程源自动识别枝江/Bilibili 直播，直播期间自动暂停本地小游戏，结束后恢复。与 [A-SOUL 与 B 站](功能-A-SOUL与B站.md) 的播报功能相互独立。

## 日程源

- 主数据：<https://raw.githubusercontent.com/Evelynall/ASoul-Data/main/base-schedules.json>
- 前端与格式：<https://github.com/Evelynall/ASoul-Calendar>
- 原始枝江日程站：<https://asoul.love/>

机器人只接受 `liveRoomUrl` 是 `live.bilibili.com` 的项目；线下活动、空间链接和录播链接不触发防护。抓取失败、空响应或格式异常不会解释成“没有直播”，而是保留上一次有效缓存。

## 自动规则

- 启动时立刻刷新，之后默认每 5 分钟刷新一次；缓存范围是当前到未来 7 天，并保留刚开始且尚在暂停窗口内的直播。
- 到达开播时间后关闭“小游戏全局总开关”；默认暂停 60 分钟，同一小时有新开播时以最后一场重新计算倒计时。
- 倒计时到期后自动恢复小游戏总开关；超级管理员可用 `#总游戏开` 提前恢复，已处理的同一场直播不会重复关闭。
- 该开关只拦截本地小游戏，不影响 [异环游戏接口](功能-异环游戏接口.md)。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `#枝江直播` / `#直播日程` | 查看未来 7 天缓存。 |
| `#枝江直播 状态` | 查看防护开关、当前小游戏总开关、暂停截止时间和最近刷新状态。 |
| `#刷新枝江直播` | 仅超级管理员立即刷新；失败时继续使用本地缓存。 |
| `#总游戏开` / `#总游戏关` | 仅超级管理员人工控制全局小游戏开关。 |

## 配置

```dotenv
ZHIJIANG_LIVE_GUARD_ENABLED=true
ZHIJIANG_SCHEDULE_URL=https://raw.githubusercontent.com/Evelynall/ASoul-Data/main/base-schedules.json
ZHIJIANG_SCHEDULE_REFRESH_MINUTES=5
ZHIJIANG_LIVE_PAUSE_MINUTES=60
ZHIJIANG_SCHEDULE_LOOKAHEAD_DAYS=7
ZHIJIANG_SCHEDULE_TIMEOUT=15
```

`ZHIJIANG_SCHEDULE_URL` 必须是 HTTP(S) 地址；停用自动防护时把 `ZHIJIANG_LIVE_GUARD_ENABLED=false`。修改配置后重启 NoneBot。
