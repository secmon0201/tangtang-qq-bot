# 功能：查重与白名单

跨群成员查重和白名单维护，仅超级管理员可用。结果以本地 Pillow 图片或自动分段的文字回退返回。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `#查重1 [群号...]` | 指定群互相查重（省略时用配置范围），保留白名单成员。 |
| `#查重2 <起点群> <目标群...>` / `#查重 <起点群> <目标群...>` | 起点群对目标群查重，保留白名单成员。 |
| `#查重3 [群号...]` | 全量互查，忽略白名单。 |
| `#查重4 <起点群> <目标群...>` | 起点/目标查重，忽略白名单。 |
| `#白名单 添加 <QQ号> [备注]` / `#白名单 删除 <QQ号>` | 维护查重白名单。 |
| `#白名单 列表` / `#白名单列表` / `#白名单菜单` | 查看白名单；支持私聊。 |

## 行为规则

- `查重1/2` 使用白名单，`查重3/4` 忽略白名单；旧命令 `#查重` 兼容 `#查重2`。
- 省略群号时，`#查重1/#查重3` 使用全部管理群互查，`#查重2/#查重4` 使用全部管理群并以列表第一个群为起点群。
- 结果合并为一张本地图片，图片高度随人数增长；文字回退超长时自动分段，不再提供 `页2` 分页。
- 同一次扫描结果使用临时快照，5 分钟内不因群成员变化改变总数；图片顶部显示群编号映射，`#查重1` 标记“参与查重”，`#查重2` 标记“起点/目标”。
- 跨群结果只对超级管理员开放；白名单变更写入审计记录。

## 配置

- `DUPLICATE_GROUP_IDS`：查重允许使用的群号子集；不填写时继承全部 `MANAGED_GROUP_IDS`。
- `DUPLICATE_SCAN_COOLDOWN_SECONDS`：扫描冷却。
