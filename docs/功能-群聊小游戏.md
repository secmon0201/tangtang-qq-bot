# 功能：群聊小游戏

群内可玩的俄罗斯转盘、定时炸弹、成语炸弹、幸运骰局和猜数字，以及各自的本群/群域榜。所有小游戏指令都必须以 `#` 开头。

## 可用范围

需要小游戏全局总开关和本群游戏开关均为开启；直播守卫暂停时会自动停玩，恢复后继续。今日老婆不受小游戏开关影响。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `#游戏列表` / `#小游戏列表` | 发送小游戏菜单和玩法图片。 |
| `#装填` / `#开枪` | 发起或继续俄罗斯转盘。 |
| `#装弹` / `#丢给 @成员` | 发起或传递定时炸弹。 |
| `#装弹成语 [专业/娱乐] [60-600]` | 发起成语接龙定时炸弹；省略时默认专业模式、120 秒。 |
| `#骰子` / `#猜数` / `#猜 <0-999>` | 幸运骰局与猜数字。 |
| `#转盘榜`、`#炸弹榜`、`#骰子榜`、`#猜数榜` | 查看本群榜。 |
| 对应 `#...总榜` | 查看当前群域；独群仍只含本群，集群合并当前集群。 |
| `#群设置 小游戏 开|关` / `#开关小游戏` | 本群机器人管理员控制当前群。 |
| `#系统设置 小游戏 全局 状态|开|关` | 超级管理员私聊维护全局运行条件。 |
| `#系统设置 小游戏 禁言 <群号> 状态|开|关` | 管理随机禁言；仅机器人是群主或管理员时生效。 |
| `#清游`，60 秒内 `#确认` / `#取消` | 仅清理小游戏数据，不影响今日老婆。 |

完整命令、别名和玩法见 [全部 `#` 指令清单](全部#指令清单.md)。

## 行为规则

- 俄罗斯转盘允许同一成员在同一把枪中连续开枪，但每局只记一次参局；幸运骰局每人每局一次投掷；定时炸弹仅当前持有者可传递。
- 群域榜绝不跨越当前独群/集群；只有 NTE 的显式机器人总榜能跨群。直播防护只暂停启用防护群的新开局，不影响 [异环游戏接口](功能-异环游戏接口.md)。
- 所有对局状态和战绩保存在本地 SQLite，重启后恢复。

## 配置

- `GAME_GROUP_IDS`：旧配置迁移种子；运行中的群开关以 SQLite 为准。
- `MINI_GAME_GUESS_CURSED_NUMBERS`：猜数字触发配置。
