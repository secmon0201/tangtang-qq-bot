# 功能：被动互动

只读指定群普通发言的自动互动：随机表情、随机复读和三连复读。糖糖主动回复是独立功能，见 [糖糖聊天](功能-糖糖聊天.md)。

## 可用范围

只在已启用的被动互动群生效；过滤名单用户、机器人自身消息和 `#` 命令不参与。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `#群设置 被动互动 开|关` / `#开关被动互动` | 群主、群管理员或超级管理员修改当前群总开关。 |
| `#系统设置 被动互动 <群号> 状态` | 超级管理员私聊查看指定群参数。 |
| `#系统设置 被动互动 <群号> <参数> <值>` | 设置表情/复读概率、冷却、间隔和三连复读参数。 |

## 行为规则

- 每个群都有独立配置，修改一个群不影响其他群；参数持久化到 SQLite。
- 随机表情受命中率和冷却影响；随机复读只对纯文本且长度合适的消息生效，并满足消息间隔与冷却。
- 三连复读在连续三条相同纯文本后按概率额外复读一次，不占用、也不刷新随机复读冷却；概率未命中时消息仍可进入随机复读判断。
- SQLite 是逐群开关与参数的运行权威；`.env` 列表只作为旧配置迁移种子，群内操作不反写 `.env`。
- 被动互动会阻断该消息继续进入其他命令处理。

## 配置

- `BOT_RANDOM_REACTION_ENABLED` / `BOT_RANDOM_REACTION_GROUP_IDS`：随机表情总开关与群列表。
- `BOT_RANDOM_REPEAT_ENABLED`、`BOT_RANDOM_TRIPLE_REPEAT_ENABLED`：随机复读与三连复读总开关。
- 逐群概率、冷却、间隔通过命令热更。

## 维护与验证

概率、冷却、幂等和过滤规则见 `tests/test_random_reactions.py`、`tests/test_triple_repeat.py`、`tests/test_passive_settings.py`。
