# 功能：跨群活动

跨群创建、报名和结果广播。活动只在 `ACTIVITY_GROUP_IDS` 范围内的群可用，状态和报名数据保存在本地 SQLite。

## 角色与权限

- 超级管理员：管理全部活动，可在私聊创建和管理。
- 活动管理员（`ACTIVITY_ADMIN_IDS` 或活动有效群的群主/群管理员）：只能创建并管理自己创建的活动；黑名单成员不获得自动权限。
- 普通用户：查看、报名、取消报名和查看获奖名单；不能创建、修改、取消或提前结束。
- 活动创建者可在私聊管理自己创建的活动；目标群必须属于 `ACTIVITY_GROUP_IDS`。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `#活动帮助` / `#活动管理员帮助` | 查看普通用户或管理员的帮助。 |
| `#活动大厅` / `#活动详情 <ID>` / `#查看名单 <ID>` / `#获奖名单 <ID>` | 查看活动、名单和结果。 |
| `#报名 <ID>` / `#取消报名 <ID>` / `#我的活动` | 报名和取消；ID 前可用空格、中文冒号或 `#`。 |
| `#创建活动 活动名：...` | 每项单独换行填写开始/结束时间、类型、说明、奖项、参与群、隐私。 |
| `#修改活动 活动ID：...` | 只改填写或留空的字段；进行中的活动仅超级管理员可修改。 |
| `#活动网页` / `#活动面板` | 活动管理员获取一次性活动管理页，用表单创建、修改、结束或取消自己可管理的活动。 |
| `#提前结束 <ID>` / `#取消活动 <ID> [原因]` | 提前结束或软删除活动。 |

完整命令和参数见 [全部 `#` 指令清单](全部#指令清单.md)。

## 活动网页

活动管理员、活动有效群的群主/管理员和超级管理员可发送 `#活动网页`。链接 15 分钟有效，仅授予本次活动管理能力：可用时间选择器、参与群勾选和奖项输入创建/修改活动，并查看状态、提前结束或取消有权限的活动。普通成员的报名、取消报名和大厅查看仍在 QQ 内完成。

固定域名模式使用 `https://tangtang.secmon.cn/activity/<令牌>`；统一公网网关把该路径映射到本功能既有的 `/operator/*` 能力接口。域名生效前仍可用 `启动工具\26-启动运营网页隧道.bat` 启动独立 Quick Tunnel，它只接受活动、运营和查重三类公开路径及旧 `/operator/*` 兼容路径。统一地址规划见 [网页地址与固定隧道](运维-网页地址与固定隧道.md)。

## 创建示例

```text
#创建活动 活动名：跨群抽奖
开始时间：2026-08-25 20:00
结束时间：2026-08-25 22:00
类型：抽奖
说明：报名抽奖
奖项：一等奖=1；二等奖=2
参与群：1067772451,278824712
隐私：脱敏
```

抽奖必须填写奖项，通报不填奖项。旧的竖线 `|` 分隔格式继续兼容。

## 行为规则

- 活动 ID 从 500 起连续生成，旧 ID 不因重启改变；`#取消活动` 是软删除，冻结报名并保留审计记录。
- 报名、重复报名和取消报名只给原消息添加“续标识”表情，不发送文字确认。
- 大厅、详情、名单和状态通知使用本地 Pillow 图片或合并转发，不调用互联网大模型；普通成员看到的跨群 QQ 号默认脱敏，创建者和超级管理员可查完整信息。
- 状态变化和抽奖结果广播到该活动所有群；结束的抽奖活动把详情与按奖项分区的获奖名单图片合并转发。
- 修改参与群后，退出群只收到“该活动已不支持本群”图片，新加入和原有群收到完整更新图片。
- 活动不执行踢人、禁言、加群审批等管理操作；重启后状态、报名、中奖结果和待发送广播从 SQLite 恢复。

## 配置

- `ACTIVITY_GROUP_IDS`：活动可用群；不填写时继承全部 `MANAGED_GROUP_IDS`。
- `ACTIVITY_ADMIN_IDS`、`ACTIVITY_ADMIN_BLACKLIST_IDS`：活动管理员和自动权限排除名单。
- `ACTIVITY_MAINTENANCE_INTERVAL_SECONDS`、`ACTIVITY_BROADCAST_MAX_ATTEMPTS`：维护周期和广播重试。
