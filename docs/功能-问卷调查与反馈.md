# 功能：问卷调查与反馈

超级管理员发布问卷公告收集意见；普通用户在受管群或私聊用 `###反馈内容` 提交建议。这不是投票功能。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `#创建问卷调查` / `#创建问券调查` | 创建问卷。 |
| `#结束问券调查` / `#结束问卷调查` | 结束进行中的问卷。 |
| `#问券调查列表` / `#问卷调查列表` | 查看可用问卷。 |
| `#查询问券调查` / `#查询问卷调查` | 查看指定问卷。 |
| `#发送问券调查 <问卷ID>` | 将公告图片和文字说明作为同一条普通群消息发送到全部目标群；发布新公告会自动结束此前公告。 |
| `###反馈内容` | 受管群或私聊提交反馈。 |
| `#查看反馈 [问卷ID] [-页码]` / `#反馈意见清单` / `#反馈列表` | 仅超级管理员，以合并转发查看反馈。 |

## 行为规则

- 问卷由超级管理员创建、发送和结束，不提供 `#问卷ID` 投票。
- 反馈保存所属问卷 ID、QQ 号、来源群（私聊标记为私聊）、提交时间和正文；每隔 `FEEDBACK_NOTIFICATION_INTERVAL_SECONDS` 秒私聊通知所有超级管理员。
- 每页最多 200 条，每 20 条一个合并转发节点，每 10 个节点一条合并转发；该管理交互不生成图片。

## 配置

- `FEEDBACK_NOTIFICATION_INTERVAL_SECONDS`：新反馈私聊通知超级管理员的间隔。
