# 鸣潮游戏接口

## 功能边界

鸣潮使用 XutheringWavesUID，上游普通查询、登录、面板、抽卡和攻略命令继续由 GsUID Core 处理。项目侧只在 NoneBot 入口截断帮助、明确支持的排行榜和已关闭功能命令，加工只读数据/资源后回复；未匹配消息继续发送上游，不重写其他上游功能；兼容 `#ww`、`ww`、`ww ` 及大小写变体。原神等其他游戏前缀保持禁用。

安装脚本同时安装 RoverSign、TodayEcho、ScoreEcho 和 RoverReminder，并统一保留 `ww` 强制前缀。RoverSign、TodayEcho 和 ScoreEcho 默认启用；RoverReminder 仅保留安装，其插件加载和内部 `EnableStaminaPush` 邮件开关均由项目固定关闭，不需要配置 SMTP 邮箱或授权码。`HelpExtraModules=["all"]` 仍保留，因此上游原版帮助快照可能列出 RoverReminder，但不代表运行时已启用。用户调用 `#ww推送邮箱`、`#ww开启体力推送`、`#ww推送阈值` 等 RoverReminder 命令时，NoneBot 会拦截并明确回复功能已关闭，不保存设置、不查询体力也不发送邮件。

ScoreEcho 继续使用当前上游配置。上游已对 API HTTP 错误返回状态码和服务端错误详情；测试 token 失效时沿用该原版失败提示，不额外覆盖正常结果或上游错误文本。

鸣潮是一项默认开启的独立群功能：新加入的受管群和升级前已存在的受管群都会单独保存 `ww=开`，不继承也不改写 NTE 的群开关。本群管理员可用 `#群设置 鸣潮 开|关` 或 `#开关鸣潮` 修改当前群开关。超级管理员私聊 `#系统设置 游戏接口 开|关` 控制 NTE 与鸣潮共用的全局运行条件；全局关闭不会覆盖任何群设置。

## 排行榜

- `#ww<角色>评分排行`、`#ww<角色>声骸排行`、`#ww练度排行`、`#ww最强排行`：只看当前群。
- 对应的 `总排行`：只看当前机器人本地保存的全部鸣潮绑定与面板缓存。
- 支持末尾数字、`页2` 或 `第2页`，每页最多 100 条；本人不在当前页时追加真实名次。
- 不提供 A 海岸鸣潮榜，不请求上游公共总榜，也不会把私有集群当作鸣潮统计范围。

`#ww<角色>排行` 是上游伤害排行，不由项目拦截；抽卡、无尽、矩阵等活动排行以及带 `ss` 等项目尚未实现的上游格式也原样交给 Core，避免把“长离伤害”等文本误当成角色名。

榜单保留角色、等级、共鸣链、武器、武器等级、谐振等级、声骸套装和评分，并补充 QQ 头像、QQ 昵称、UID、来源群和群代称。数据读取链为 `GsData.db:wavesbind`、`data/XutheringWavesUID/players/<uid>/charListData.json` 和压缩或明文 `rawData.json`，全部只读。

## 帮助

- `#ww帮助` / `ww帮助`：简约版，包含常用普通功能及四个已安装扩展的入口，不显示管理命令。
- `#ww完整帮助` / `ww完整帮助`：完整版，包含当前上游全部普通命令、扩展命令、群管理员命令和 Bot 主人命令；权限仍由上游校验。
- `#ww原版帮助`：使用 `scripts/export_wuwa_original_help.py` 生成的上游帮助快照。

`scripts/sync_wuwa_help.py` 从当前 XutheringWavesUID 与扩展帮助 JSON 确定性生成简约版和完整版资源；测试会检查完整版未漏掉任何上游条目。

## 登录地址

`#ww登录` 使用 `https://tangtang.secmon.cn/waves/i/<临时令牌>`。固定隧道启动脚本会把 XutheringWavesUID 的 `WavesLoginUrl` 写为该 HTTPS 域名，并打开 `WavesLoginUrlSelf`，然后按需重启 Core 使配置生效。

统一网关只向 Core 转发鸣潮临时登录页及其提交接口；`/waves/panel-edit/*`、`/waves/gacha/*`、`/waves/fonts/*`、外置登录服务接口、`/ws/*` 和 `/api/*` 均不公开。手机号、验证码、邮箱、密码、Cookie 和登录态只在用户浏览器、Core 与库洛登录接口之间处理，不经过 NoneBot，也不写入项目日志。

## 既有数据导入

外部数据尚未提供时不得执行真实导入。收到既有 Bot 的 `GsData.db` 和 `XutheringWavesUID/players` 后，先运行 dry-run：

```powershell
.\.venv\Scripts\python.exe scripts\import_wuwa_data.py --source-db 'D:\旧机器人\data\GsData.db'
```

审计结果只输出表行数、用户数、UID 数、玩家目录数和冲突摘要，不输出 Cookie、Token 或登录信息。只有确认来源严格限于 A 海岸五群后，先停止 GsUID Core，再增加 `--apply`；工具会先备份目标数据库和冲突玩家目录，再按自然键合并且不复制源表自增 ID。导入完成并验证表行数与榜单后再启动 Core。

## 上游边界

不得修改或提交 `GsUID.Core`、XutheringWavesUID、四个扩展及其数据库、玩家缓存和登录状态。上游版本只记录在 `config/upstream-lock.json`；`scripts/install_gsuid.ps1` 从该文件读取仓库，自动修复 tracking，只允许 fast-forward，并拒绝改动、未跟踪文件、stash、本地提交和分叉。更新后先运行 `scripts/sync_wuwa_help.py`，再运行 `scripts/validate_upstream_lock.py` 与 `scripts/validate_nte_mode.py`。
