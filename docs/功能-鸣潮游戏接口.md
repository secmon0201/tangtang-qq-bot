# 鸣潮游戏接口

## 功能边界

鸣潮使用 XutheringWavesUID。所有 `#ww`/`ww` 命令，包括帮助、登录、面板、抽卡、攻略和排行，均由 GsUID Core 原样处理；本项目只在 NoneBot 消息入口保留群范围、黑名单和 `ww` 功能开关门。原神等其他游戏前缀保持禁用。

上游安装目录可包含 RoverSign、TodayEcho、ScoreEcho 和 RoverReminder；这些插件及其帮助扩展由 GsUID Core 自身配置决定。本项目不拦截或改写上游插件命令。

ScoreEcho 继续使用当前上游配置。上游已对 API HTTP 错误返回状态码和服务端错误详情；测试 token 失效时沿用该原版失败提示，不额外覆盖正常结果或上游错误文本。

鸣潮是一项默认开启的独立群功能：新加入的受管群和升级前已存在的受管群都会单独保存 `ww=开`，不继承也不改写 NTE 的群开关。本群管理员可用 `#群设置 鸣潮 开|关` 或 `#开关鸣潮` 修改当前群开关。超级管理员私聊 `#系统设置 游戏接口 开|关` 控制 NTE 与鸣潮共用的全局运行条件；全局关闭不会覆盖任何群设置。

## 上游功能

帮助、排行、面板、抽卡和攻略均使用上游 XutheringWavesUID 的原始命令和渲染。项目不生成或发送本地鸣潮排行/帮助图，也不把自然语言请求转换为本地鸣潮动作。

## 帮助

`#ww帮助` / `ww帮助` 直接返回上游 XutheringWavesUID 帮助；权限仍由上游校验。

## 登录地址

`#ww登录` 的地址由上游 XutheringWavesUID 配置控制。固定隧道启动脚本只启动项目网页网关，不改写上游配置，也不重启 Core。

统一网关只向 Core 转发鸣潮临时登录页及其提交接口；`/waves/panel-edit/*`、`/waves/gacha/*`、`/waves/fonts/*`、外置登录服务接口、`/ws/*` 和 `/api/*` 均不公开。手机号、验证码、邮箱、密码、Cookie 和登录态只在用户浏览器、Core 与库洛登录接口之间处理，不经过 NoneBot，也不写入项目日志。

## 数据边界

项目不导入、重排或修复上游 `GsData.db`、玩家目录和登录缓存。已有上游数据由 XutheringWavesUID 自己管理；如需迁移或恢复，遵循上游提供的工具和备份流程，不使用项目侧的旧导入脚本。

## 上游边界

不得修改或提交 `GsUID.Core`、XutheringWavesUID、四个扩展及其数据库、玩家缓存和登录状态。上游版本只记录在 `config/upstream-lock.json`；`scripts/install_gsuid.ps1` 从该文件读取仓库，自动修复 tracking，只允许 fast-forward，并拒绝改动、未跟踪文件、stash、本地提交和分叉。更新后运行 `scripts/validate_upstream_lock.py` 与 `scripts/validate_nte_mode.py`。
