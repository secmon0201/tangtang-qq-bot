# 异环本地接管维护说明

本文档描述当前已经运行的 NTE 本地接管边界，不是实施计划或历史设计稿。

## 运行边界

- 游戏链路为 `NapCat -> NoneBot2 -> GenshinUID 连接器 -> GsUID.Core -> NTEUID`。
- Core 中只启用 NTEUID；GenshinUID 和 XutheringWavesUID 保持关闭。
- 用户文档统一使用 `#nte`。裸 `nte` 仅作为连接器兼容入口，不作为公开指令格式宣传。
- 排行榜、帮助图和匹配命令由本项目接管；其他 NTE 查询继续交给上游。

## 项目所有权

| 责任 | 当前实现 |
| --- | --- |
| 命令拦截 | `bot/plugins/nte_game_ui.py` |
| 排行数据与只读 SQL | `bot/services/nte_rank_data.py` |
| 排行渲染 | `bot/services/nte_rank_render.py` |
| 帮助渲染 | `bot/services/nte_help_render.py` |
| 帮助数据 | `bot/resources/nte_help.json` |
| 角色图刷新 | `bot/services/nte_rank_render.py` 的通用刷新路径 |
| Core 运行兼容 | `bot/integrations/gsuid_core_compat.py` |
| 上游版本 | `config/upstream-lock.json` |

项目代码不得修改 `GsUID.Core` 或 NTEUID。排行榜通过 SQLite 只读 URI 打开 `GsUID.Core/data/GsData.db`；上游帮助快照由 `scripts/export_nte_original_help.py` 重新生成，生成物不进入 Git。

## 排行规则

- A 海岸群默认查看五群总榜，其他管理群默认查看全机器人榜。
- `群` 参数查看当前群；兼容的 `bot` 参数不在公开帮助中展示。
- 所属群取账号最近一次面板刷新所在群；同时间按较小群号稳定决胜。
- 排序、分页、本人溢出行和固定群别名由 `tests/test_nte_rank.py` 保护。
- 角色原图按数据库出现的角色 ID 通用刷新；失败时保留最后一张有效缓存，不做错误角色替换。

## 上游更新

1. 先停止 GsUID Core。
2. 运行 `scripts/install_gsuid.ps1`；任何上游脏文件都会使脚本停止。
3. 检查 `config/upstream-lock.json` 的版本变化。
4. 运行下面的验证。
5. 启动 Core，只重启 NoneBot，验证 `#nte帮助`、排行和普通查询。

```powershell
.\.venv\Scripts\python.exe scripts\validate_upstream_lock.py
.\.venv\Scripts\python.exe scripts\validate_nte_mode.py
.\.venv\Scripts\python.exe -m pytest tests\test_game_api.py tests\test_nte_rank.py tests\test_nte_prefix_display.py tests\test_gsuid_core_compat.py
```

任何适配都应落在 `bot/integrations`、`bot/services` 或 `bot/plugins`，不能以 stash、补丁文件或上游工作树修改的形式保存。
