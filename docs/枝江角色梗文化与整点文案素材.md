## 企划与共同文化

### 枝江世界观

枝江娱乐沿用枝江城市、枝江大学和舞台梦想的世界观。粉丝常把“上课、赶作业、排练、食堂、宿舍、舞台”与直播花絮混在一起，形成一种校园日常式的二创语气。整点文案可以借用“晚自习、校钟、排练室、食堂窗口、广播站”等意象，但不要伪装成官方剧情。

### 一个魂与各自粉丝名

A-SOUL 的团体粉丝常称“一个魂”；一期成员的粉丝称呼包括贝极星、嘉心糖、奶淇琳等。心宜的粉丝名为心球仪，思诺的粉丝名为小海诺。文案中可以把这些称呼写成星体、糖果、奶茶、轨道、海风等文学意象，但不应在没有上下文时频繁点名粉丝群体。

### 阿草与工具人文化

阿草是枝江文化中很重要的吉祥物和工具人意象。粉丝会把“幕后准备、道具搬运、公告、剪辑、秩序维护”戏称为阿草的工作。适合写成“草叶在后台盖章”“一只阿草推着钟走过走廊”之类轻松的拟人化表达，不涉及现实工作人员身份猜测。

### 小作文与怪文书

嘉然相关的粉丝文化尤其擅长把普通动态扩写成抒情、夸张、缝合、半认真半玩笑的长句。整点文案采用“文艺外壳 + 生活细节 + 最后落到一个梗”的结构，就是对这类文化的原创借鉴。

## 五位角色的梗文化整理

### 1. 贝拉 Bella

公开角色标签：A-SOUL 队长、舞蹈担当、武术担当，常被粉丝视为可靠、认真、照顾成员的人。

稳定的粉丝称呼和梗：

- 粉丝名“贝极星”，常与空间站、星轨、月光等意象组合。
- “贝武神”“中国队长”“地狱管家婆”是围绕队长、动作能力和管理气质形成的戏称。
- “大聪明”“憨憨”“勇敢牛牛，不怕困难”来自可靠与偶尔笨拙之间的反差。
- “每人加练一天”适合当作队长式玩笑，表达排练认真、要求严格。
- 早期舞蹈视频、翻跟头、舞蹈数量和生日会舞台常被粉丝用来强调“舞担含金量”。

适合转写的文案母题：队长查寝、舞台灯光、月光加冕、星际排练、认真管理、勇敢但不失可爱。

### 2. 嘉然 Diana

公开角色标签：可爱担当、元气、吃货，擅长用轻松语气和观众互动。

稳定的粉丝称呼和梗：

- 粉丝名“嘉心糖”，常与甜味、草莓、糖纸、点心等意象联用。
- “关注嘉然，顿顿解馋”是最适合做报时文案暗线的口号型梗。
- 干饭、薯片、可乐、吃辣困难等饮食话题构成长期的生活化笑点。
- “小恶魔”“主人”是直播互动中形成的反差称呼，使用时保持轻松，不写成命令或冒犯。
- “一米吧”、粉色矮子、小羽毛球等是身高、外形或口误延伸出的粉丝玩笑。
- “圣诞礼物”“日在校园”、宅舞串烧和“小作文/怪文书”是粉丝二创记忆中的高识别度节点。

适合转写的文案母题：糖纸包裹的钟声、草莓色晚霞、食堂窗口、辣椒远征、文豪投稿、甜味陷阱。

### 3. 乃琳 Eileen

公开角色标签：姐系角色、MC、深夜电台式杂谈、知识科普和强控场能力。

稳定的粉丝称呼和梗：

- 粉丝名“奶淇琳”，适合与奶油、茶杯、夜班电台、蓝色月光搭配。
- “乃琳Queen”“乃王木木”“小狐狸”是常见称呼；“乃琳困”来自状态和表情的二创玩笑。
- “坏女人/好女人”描述的是会控场、会开玩笑但本人容易害羞的反差。
- 早期深夜电台、希腊神话、刑法和生活科普构成“知性广播站”印象。
- 奶淇琳常用夸夸、接梗和电台听众的语气进行二创；适合写成“今晚请收听一条来自月面的夸夸”。
- 《Sweet Counter》《Hey Lin》等音乐节点可化成“甜点柜台、夜班收音机、蓝色唱片”等隐喻，不直接改写歌词。

适合转写的文案母题：午夜电台、蓝色高跟鞋、法条与月亮、温柔控场、夸夸群、狐狸尾巴。

### 4. 心宜 Fiona

公开角色标签：“闪耀舞台”成员，元气、开朗、行动力强，舞蹈表现有力量感。

稳定的粉丝称呼和梗：

- 粉丝名“心球仪”；“今日宜心动”和“关注心宜，心旷神宜”是适合转写的文字游戏。
- “枝江小太阳”“小海豹”来自她的活力、鼓掌打 call 和拍肚皮等可爱互动。
- “保洁阿宜、食堂阿宜、扫地阿宜”等称呼，体现粉丝把她想象成无处不在、什么都能做的校园角色。
- “心宜不是心仪”是名字读写上的常见文字梗。
- “傻人有傻福”与“每次直播都很有精神”形成元气、直率和呆萌的反差。
- 手工、儿童卡纸、赛博蛋糕等花絮适合写成“认真完成但审美另有宇宙”的轻松笑点。

适合转写的文案母题：粉色太阳、海豹鼓掌、校园保洁车、心动天气预报、手工课、全力起跳。

### 5. 思诺 Gladys

公开角色标签：“闪耀舞台”成员，声乐科班出身，常以歌回、音乐知识和沉稳的杂谈建立角色辨识度。

稳定的粉丝称呼和梗：

- 粉丝名“小海诺”，二创话题常见“嘀嘀嘀吹”等带有广播、海风和小动物感的表达。
- “枝江邓紫棋”“声乐老师”来自歌唱风格与专业分享；“大狮子”则是形象和气质上的戏称。
- “八老师”“诺姐”“小种子”是常见称呼，适合分别转写成讲台、夜校、森林成长等意象。
- 单人首播后“要不要回去考研”成为粉丝调侃，使用时要写成紧张后的自我吐槽，不涉及现实升学判断。
- 舞蹈是她与心宜之间很有辨识度的反差：声乐老师教唱歌，元气搭档教跳舞，粉丝常把两人的合作戏称为“包办婚姻”。这是二创玩笑，不是官方关系设定。
- “小种子”与音乐剧式故事、歌唱成长和认真坚持有关；“狮步重踏”、广播体操等是舞蹈反差的轻松梗。

适合转写的文案母题：森林里的小种子、深夜练声、海风收音机、考研通知书、狮子学跳舞、声乐课点名。

## 整点报时功能实现说明

整点报时功能已经接入机器人，但默认关闭。启用前请先加入群范围并设置时段；实际命令和运行流程以项目总手册为准。当前实现边界如下：

- 只在管理员指定的群范围内发送，默认关闭，不影响现有 @ 回复和被动互动。
- 支持总开关、群范围、开始时间、结束时间，以及从分段素材和花名分类中随机组合文案。
- 所有热更新写入 SQLite，重启后保留；管理员命令需要图文反馈并显示群头像、群名和群号。
- 每个整点最多发送一条，使用本地时间区和明确的任务幂等键，避免重复发送。
- 发送失败只做有限重试，不进行高频重试；日志记录任务时间、群号、文案编号和错误类型，不记录不必要的群聊原文。
- 文案池应作为独立资源文件或数据库表维护，未来可以增加、停用、分组和按角色筛选，不把角色梗硬编码在调度器里。当前分段源为 `bot/resources/zhijiang_hourly_copy.json`，花名源为 `bot/resources/zhijiang_character_aliases.json`，四个时段各有 before/middle/after 三组可手工补充的片段。
- 花名按 `asoul` 与 `other` 分类维护；`other` 下已经包含鸣潮角色、群聊中性称呼和枝江公共意象，分段可以通过 `name_categories` 选择可用范围。
- 当前四个时段各有前、中、后三个至少 100 条素材的分段，按纯文案计算共有 5,185,596 种源文案组合；`python scripts/generate_hourly_copy.py --sample 8` 会校验最低数量、重复项、花名和理论组合数，并查看运行时组合样例。
- 糖糖聊天记录库中的真实用户原话不直接进入文案池，只抽象公共口头禅和节奏，避免把个人昵称、原话或私人信息变成固定广播。
- 管理员命令：`#整点报时 状态|开启|关闭|时段 HH:MM HH:MM|范围 添加|移除|列表 QQ群号`。
- 文案池修改后需要重启机器人重新加载；启停、时段和群范围通过命令热更新并永久保存。
