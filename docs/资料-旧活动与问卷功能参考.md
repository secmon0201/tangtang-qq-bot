# 旧活动与问卷功能参考

跨群活动和问卷/反馈功能自群域架构上线后不再注册、加载或对用户提供。它们不是当前可用功能，也不出现在命令清单、普通帮助、公开站、网关白名单或图片审查包中。
旧 SQLite 表和既有记录保持原状，仅作为历史数据，不参与任何后台任务。

完整旧实现保留在 Git 提交 `89b4e67`。需要重新设计时，只通过 Git 历史读取参考，不得直接恢复旧插件：

- `git show 89b4e67:bot/plugins/activities.py`
- `git show 89b4e67:bot/services/activities.py`
- `git show 89b4e67:bot/plugins/surveys.py`
- `git show 89b4e67:bot/services/surveys.py`
- `git show 89b4e67:docs/功能-跨群活动.md`

- `git show 89b4e67:tests/test_activities.py`
- `git show 89b4e67:tests/test_surveys.py`

当前源码不再创建、迁移或访问旧活动/问卷表，也不保留专用报告渲染入口；只有已经运行过旧版本的生产数据库可能仍存在历史表。

重新实装前必须先按当前的独群/集群、群管理员权限、群功能开关和公告面板重新确定产品契约。
不得把旧活动或问卷命令直接注册回生产插件表。未来需要时，应先按当前群域权限、目标多选、令牌轮换和视觉规范重新设计，再作为新功能完整实现、测试和登记。
