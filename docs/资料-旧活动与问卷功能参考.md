# 旧活动与问卷功能参考

跨群活动和问卷/反馈功能自群域架构上线后不再注册、加载或对用户提供。
旧 SQLite 表和既有记录保持原状，仅作为历史数据，不参与任何后台任务。

需要重新设计这两项能力时，应从 Git 历史恢复到独立分支参考，不得直接恢复旧插件：

- `bot/plugins/activities.py` 与 `bot/services/activities.py`：跨群活动、报名、开奖和广播。
- `bot/plugins/surveys.py` 与 `bot/services/surveys.py`：问卷公告、反馈记录和通知。
- `docs/功能-跨群活动.md` 与 `docs/功能-问卷调查与反馈.md`：旧用户和维护说明。
- `tests/test_activities.py` 与 `tests/test_surveys.py`：旧行为契约。

重新实装前必须先按当前的独群/集群、群管理员权限、群功能开关和公告面板重新确定产品契约。
不得把旧活动或问卷命令直接注册回生产插件表。
