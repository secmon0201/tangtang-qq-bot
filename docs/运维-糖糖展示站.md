# 运维：糖糖展示站

`site/` 是糖糖与 A 海岸公开多页介绍站的本机兼容产物，由 Git 忽略；可维护源码位于 `site-src/`。固定地址为 `https://tangtang.secmon.cn/`。展示站和机器人网页共用同一个 Named Tunnel：公开页面及静态资源由 `scripts/tangtang_web_gateway.py` 直接提供，只读直播日历使用 `/live/*`，群发言榜使用 `/ranking/*`，普通用户帮助使用 `/help/*`，`/notice/*`、`/activity/*`、`/operations/*`、`/duplicate/*` 和 `/nte/*` 继续进入各自服务，因此不会发生路由冲突。

公开页面按受众和主题拆分，不能再把全部信息堆进首页：

- `/`：面向普通群友的第一印象和九宫格体验地图；
- `/experience/`：资讯、聊天、社交互动和社区记忆；
- `/games/`：本地小游戏与项目自主管理的 NTE 帮助、排行及范围分流；
- `/community/`：A 海岸五群、跨群统计、活动与档案；
- `/operator/`：面向拥有者和管理员的公告、活动、范围、权限与维护能力；
- `/technology/`：Windows 本地运行链、代码边界、固定隧道和安全白名单；
- `/release/`：未来 GitHub 发布入口，未发布前只显示“敬请期待”。

A 海岸群号按用户要求公开展示并支持复制；管理员账号、权限名单、内部接口、令牌、Cookie 和运行数据不得进入静态站。

当前兼容产物的本地预览：

```powershell
.\.venv\Scripts\python.exe -m http.server 4173 --directory site --bind 127.0.0.1
```

公网主页随固定隧道启动：

```powershell
.\scripts\start_tangtang_named_tunnel.ps1 -SkipCoreRestart
```

展示站本身仍是纯 HTML/CSS/JavaScript，不调用 NoneBot、NapCat 或 GsUID Core API；但公网访问依赖本机 `127.0.0.1:18769` 网关与 Cloudflare Named Tunnel 在线。停止固定隧道后，主页和同域名机器人网页会同时离线，QQ 机器人本身不受影响。

模块化维护、临时构建、原子发布、缓存压缩、并发上限和压测方式见 `docs/运维-公开展示站模块化维护.md`。不要直接逐个覆盖正在服务的 `site/` 文件，也不要用 `http.server` 的结果判断 Brotli、ETag 或网关并发能力。

安全边界：公网只允许上述七个页面、当前版本清单登记的页面、静态资源前缀和已登记功能前缀；不能把版本目录整体暴露。`site/README.md`、`site/_headers`、构建清单、压缩 sidecar、仓库其他文件、`/ws/*`、`/api/*`、`/internal/*` 与路径穿越请求均不公开。
