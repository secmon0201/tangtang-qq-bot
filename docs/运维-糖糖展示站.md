# 运维：糖糖展示站

`site-src/` 是可维护源码，Git 忽略的 `site/` 只是本机兼容产物。固定地址为 `https://bot.example.invalid/`。公开站介绍面向所有 QQ 群的糖糖，不展示私有集群专属主页或教程。

## 页面结构

- `/`：面向所有 QQ 群的第一印象、九项当前能力、常见用例与全局总控提示。
- `/experience/`：直播日历、聊天、今日缘分、群排行和群内记忆。
- `/games/`：本地小游戏与 NTE 当前群/机器人总榜边界。
- `/operator/`：群设置、公告、查重、状态自检和维护边界。
- `/technology/`：Windows 本地运行链、代码分层、固定隧道和安全白名单。
- `/release/`：未来 GitHub 发布入口。

`/community*` 不在构建清单和导航中，必须返回 404。私有集群只存在于本地运行数据和相应群域排行中，不作为公开站内容入口。

## 机器人网页

公开站与机器人网页共用 Named Tunnel：只读直播日历使用 `/live/*`，普通帮助使用 `/help/*`，群域排行只使用 `/ranking/<令牌>/*`；`/notice/*`、`/duplicate/*`、`/nte/*` 和受限的鸣潮 `/waves/i/*` 登录链进入各自服务。鸣潮面板编辑器、抽卡网页及旧 `/activity/*`、`/operations/*`、`/community*` 不开放。

## 构建与预览

先构建到暂存目录，再通过浏览器检查桌面和移动视口。兼容产物可临时预览：

```powershell
.\.venv\Scripts\python.exe -m http.server 4173 --directory site --bind 127.0.0.1
```

公网主页由以下脚本启动：

```powershell
.\scripts\start_tangtang_named_tunnel.ps1 -SkipCoreRestart
```

公开站是纯 HTML/CSS/JavaScript，不读取 NoneBot、SnowLuma 或 GsUID Core 私有 API。停止 Named Tunnel 后，主页与同域机器人网页会离线，QQ 机器人本身不受影响。

模块化维护、临时构建、原子发布、缓存压缩和压测见 [公开展示站模块化维护](运维-公开展示站模块化维护.md)。公网只允许发布清单页面、登记静态资源和明确功能前缀；仓库文件、数据库、日志、`/ws/*`、`/api/*`、`/internal/*` 与路径穿越请求一律不公开。
