# 运维：网页地址与固定隧道

`s.secmon.cn` 用作短链接子域，`tangtang.secmon.cn` 承载糖糖主页和机器人公网功能。两者共用一个 Named Tunnel，但短链子域只允许仓库配置表登记的 `/r`、`/s`、`/h`，展示子域则按第一段路径划分公开页面和受限功能；两者不共享会话、权限或业务接口。

## 地址规划

| 公网地址 | 功能 | 本地目标 |
| --- | --- | --- |
| `s.secmon.cn/r` | QQ 日程消息的唯一短链接 | 302 到 `tangtang.secmon.cn/live/?view=week` |
| `s.secmon.cn/s` | QQ 群发言排行榜统一入口 | 302 到 `tangtang.secmon.cn/ranking/?scope=day&group=a-coast` |
| `s.secmon.cn/h` | QQ 普通用户帮助入口 | 302 到 `tangtang.secmon.cn/help/` |
| `https://tangtang.secmon.cn/` | 糖糖机器人主页 | 当前发布版本；无指针时回退本机 `site/` 兼容产物 |
| `https://tangtang.secmon.cn/live/?view=today` | 枝江直播日历 | NoneBot 只读直播日历页面与 API |
| `https://tangtang.secmon.cn/ranking/?scope=day&group=a-coast` | A 海岸今日发言榜 | NoneBot 只读统计页面与 API |
| `https://tangtang.secmon.cn/help/` | 普通用户帮助 | NoneBot 只读帮助页面与 API |
| `https://tangtang.secmon.cn/notice/<令牌>` | 全局公告编辑页 | NoneBot `/announcement/*` |
| `https://tangtang.secmon.cn/activity/<令牌>` | 跨群活动管理 | NoneBot `/operator/*` 的活动能力 |
| `https://tangtang.secmon.cn/operations/<令牌>` | 运营配置 | NoneBot `/operator/*` 的运营能力 |
| `https://tangtang.secmon.cn/duplicate/<令牌>` | 查重与白名单 | NoneBot `/operator/*` 的查重能力 |
| `https://tangtang.secmon.cn/nte/*` | NTE 登录 | GsUID Core `/nte/*` |

`scripts/tangtang_web_gateway.py` 只监听 `127.0.0.1:18769`。`config/public-short-links.json` 是短链接子域的唯一映射表；当前登记 `/r`、`/s`、`/h`，目标必须是 HTTPS，其他路径全部返回 404。帮助页中的直播与排行榜快捷按钮也从该文件的 `help_actions` 索引读取，只接受 `https://tangtang.secmon.cn` 目标。展示子域的 `GET/HEAD` 可访问当前完整版本清单登记的公开页面，以及 `assets/*`、`vendor/*` 下实际存在的内容指纹资源；未启用原子发布指针时继续兼容 `site/` 中的七个固定页面、`styles.css` 和 `app.js`。直播、群排行、帮助及其他机器人路径只映射到各自的只读或令牌化内部接口。网关不会把版本目录整体公开，`/ws/*`、`/api/*`、`/internal/*`、仓库文档、构建清单、压缩 sidecar、未登记页面、路径穿越和其他未知路径均返回 404。

主页放在根路径不会与机器人功能冲突：浏览器访问 `/` 时不会进入 NoneBot 或 GsUID Core；带令牌的网页和 NTE 登录只在各自前缀下处理。主页是否在线取决于本机统一网关和 Named Tunnel 是否正在运行，但机器人功能路径的地址和权限模型不受影响。

## 域名生效前

公告、运营和 NTE 的 Quick Tunnel 继续可用。前两类临时隧道也接受新的 `/notice/*`、`/activity/*`、`/operations/*` 和 `/duplicate/*` 地址，因此切换固定域名时不用再次修改业务链接结构。

## 首次配置

`.cn` 实名认证完成后，在 Cloudflare 添加 `secmon.cn`，再把腾讯云的域名服务器改为 Cloudflare 给出的两条地址。确认 Cloudflare 已显示域名处于活动状态后执行：

```powershell
.\scripts\configure_tangtang_named_tunnel.ps1
```

脚本会打开 Cloudflare 授权页。授权由操作者在浏览器中完成；脚本随后创建或复用 `tangtang-secmon` Named Tunnel、创建 `tangtang.secmon.cn` 与 `s.secmon.cn` 两条 DNS 路由，并把运行配置写入忽略提交的 `data\cloudflared\tangtang-web.yml`。Cloudflare 凭据保留在当前 Windows 用户的 `.cloudflared` 目录，不写入仓库。

## 启停和验证

配置完成后启动：

```powershell
.\scripts\start_tangtang_named_tunnel.ps1
```

停止并阻止 watchdog 自动恢复：

```powershell
.\scripts\stop_tangtang_named_tunnel.ps1
```

存在 `data\cloudflared\tangtang-web.yml` 时，`启动工具\01-启动全部.bat` 和 `02-重启全部.bat` 自动选择固定隧道并跳过三条 Quick Tunnel；watchdog 同时检查 Named Tunnel、统一网关监听和 Cloudflare 边缘连接。完整关闭会保留操作者此前的启停选择。

统一网关默认使用 32 个并发槽位、60 秒客户端超时和 32 MiB 请求体上限；静态文件支持连接复用、Brotli/Gzip、ETag/304 和内容指纹长期缓存。参数、压测和本机/公网指标拆分方式见 `docs/运维-公开展示站模块化维护.md`。

验收时至少检查：

- `tangtang.secmon.cn` 可解析且 Named Tunnel 日志出现 `Registered tunnel connection`。
- `s.secmon.cn/r`、`s.secmon.cn/s`、`s.secmon.cn/h` 分别 302 到日程、群发言榜和帮助页；其他未登记路径全部返回 404。
- `https://tangtang.secmon.cn/` 返回糖糖主页，静态资源正常加载。
- `https://tangtang.secmon.cn/live/?view=today` 返回可切换今日、明日、本周的直播日历；接口只提供公开日程数据。
- `https://tangtang.secmon.cn/ranking/` 返回可切换日/周/月/总与六个固定群范围的发言榜；`https://tangtang.secmon.cn/help/` 返回可切换的普通用户帮助；两者接口均只读。
- 重新发送 `#公告网页`、`#活动网页`、`#运营网页`、`#查重网页` 后得到表内固定地址。
- `https://tangtang.secmon.cn/ws/QQLocalDataBot` 和 `/api/send_msg` 返回 404。
- `#nte登录` 使用 `https://tangtang.secmon.cn/nte/*`，并能完成既有登录流程。

不要提交 `data\cloudflared`、Cloudflare JSON 凭据、`cert.pem`、Token 或 Cookie。
