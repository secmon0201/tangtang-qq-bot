# 运维：网页地址与固定隧道

`PUBLIC_SHORT_HOST` 是显式短链接子域，`PUBLIC_SITE_BASE_URL` 承载糖糖公开站和受限功能页。两者在本机 `.env` 中设置，共用一个 Cloudflare Named Tunnel，但路径均由本地网关白名单决定。下表使用 `short.example.invalid` 和 `bot.example.invalid` 作为不可解析的公开示例。

## 地址规划

| 公网地址 | 功能 | 本地目标 |
| --- | --- | --- |
| `short.example.invalid/r` | QQ 日程短链 | 302 到 `bot.example.invalid/live/?view=week` |
| `short.example.invalid/h` | 普通用户帮助短链 | 302 到 `bot.example.invalid/help/` |
| `https://bot.example.invalid/` | 糖糖公开主页 | 当前原子发布版本；无指针时回退 `site/` |
| `https://bot.example.invalid/live/*` | 枝江直播日历 | NoneBot `/asoul-live/*` 只读页与 API |
| `https://bot.example.invalid/help/*` | 普通用户帮助 | NoneBot `/help/*` 只读页与 API |
| `https://bot.example.invalid/ranking/<令牌>/*` | 群域发言榜 | NoneBot 同路径的只读令牌页与 API |
| `https://bot.example.invalid/notice/<令牌>` | 公告编辑页 | NoneBot `/announcement/*` |
| `https://bot.example.invalid/duplicate/<令牌>` | 查重与白名单 | NoneBot `/operator/*` 的查重能力 |
| `https://bot.example.invalid/nte/*` | NTE 登录 | GsUID Core `/nte/*` |
| `https://bot.example.invalid/waves/i/<令牌>` | 鸣潮登录 | GsUID Core 鸣潮临时登录页与提交接口 |

旧 `/s`、`/community*`、`/activity*`、`/operations*`、无令牌 `/ranking/`、`/api/*`、`/ws/*` 和 `/internal/*` 均返回 404。排行链接由每次主动查询或 23:50 推送附带，不需要固定短链。

## 网关边界

`scripts/tangtang_web_gateway.py` 只监听 `127.0.0.1:18769`。`config/public-short-links.json` 是短链唯一映射表，目标必须是 HTTPS。公开站只允许当前发布清单中的首页、`/experience/`、`/games/`、`/operator/`、`/technology/`、`/release/`，以及登记的指纹静态资源。

网关不会公开版本目录、仓库文档、环境配置、数据库、日志、构建清单、压缩 sidecar 或路径穿越目标。排行令牌由群域服务校验；群加入、移出、退群、重加和集群解散会轮换相关令牌。

## 首次配置

域名进入 Cloudflare 后执行：

```powershell
.\scripts\configure_tangtang_named_tunnel.ps1
```

先在 `.env` 填写 `PUBLIC_SITE_BASE_URL`、`PUBLIC_SHORT_HOST` 和 `PUBLIC_TUNNEL_NAME`。浏览器授权由操作者手工完成。脚本创建或复用该名称的 Named Tunnel，并把本机配置写入忽略提交的 `data\cloudflared\tangtang-web.yml`。Cloudflare 凭据保留在当前 Windows 用户目录，不进入仓库。

## 启停

```powershell
.\scripts\start_tangtang_named_tunnel.ps1
.\scripts\stop_tangtang_named_tunnel.ps1
```

存在固定隧道配置时，`启动工具\01-启动全部.bat` 和 `02-重启全部.bat` 会使用 Named Tunnel；watchdog 同时检查统一网关和边缘连接。普通 Python 改动只重启 NoneBot，不重启 SnowLuma/QQ。

## 验收

- `PUBLIC_SITE_BASE_URL` 中的真实域名可解析，隧道日志出现 `Registered tunnel connection`。
- `/` 与五个公开子页面返回 200，`/community/` 返回 404。
- `PUBLIC_SHORT_HOST` 对应的 `/r`、`/h` 返回正确 302，`/s` 返回 404。
- `/live/?view=today` 与 `/help/` 返回只读页面。
- 新生成的 `/ranking/<令牌>/` 可读对应群域；无令牌和旧令牌返回 404。
- 新发送的 `#公告网页`、`#查重网页` 使用固定域名和能力令牌。
- `/ws/QQLocalDataBot`、`/api/send_msg`、`/activity/`、`/operations/` 返回 404。
- `#nte登录` 使用已配置公网域名下的 `/nte/*` 并能完成既有流程。
- `#ww登录` 使用已配置公网域名下的 `/waves/i/*`；面板编辑、抽卡网页、字体和 Core 私有接口仍返回 404。

不要提交 `data\cloudflared`、Cloudflare 凭据、Token、Cookie、数据库或日志。
