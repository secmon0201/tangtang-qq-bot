# 运维：迁移与维护清单

## 迁移到新电脑

1. 停止机器人和 NapCat 守护进程。
2. 从私有 Git 仓库检出源代码、`bot/resources`、`config`、脚本和文档；通过离线安全介质另行复制 `.env`、`data/bot.db`、`NapCat.Shell` 与 `GsUID.Core/data`。
3. 新电脑安装 Python 3.13+、QQ 与 NapCat 依赖，随后在项目根目录执行 `python -m venv .venv` 和 `.venv\\Scripts\\python.exe -m pip install -e ".[dev]"`。
4. 检查 `.env` 中的绝对路径、账号和端口设置；不要将 `.env`、登录会话或数据库提交到 Git。
5. 运行 `scripts/validate_qq_config.py`，再用 `scripts/start.ps1` 启动。

## 不需要迁移

- `.venv`、`build`、`dist`、`__pycache__`、`.pytest_cache`：本机生成的 Python 环境和构建缓存。
- `logs`、根目录 `reports`：运行日志与测试/设计评审产物。
- `downloads`：可重新下载的安装包。
- `.codex/runtime`：Codex 任务运行时缓存；确认没有待处理任务后可重新生成。
- `NapCat.Shell.backup-*`、`NapCat.Shell.previous-*`、根目录 `backups`：已清理的历史版本副本。

## 日常维护

- 用 `scripts/backup.ps1` 备份 SQLite 数据库；备份会写入 `data/backups`。
- 需要重新生成管理器时运行 `scripts/build_manager.ps1`。
- 运行测试使用 `.venv\\Scripts\\python.exe -m pytest`。
- 提交前运行 `scripts/validate_repository.py`、`scripts/validate_architecture.py` 和测试套件。
- `GsUID.Core` 与 UID 插件保持独立、干净；上游版本由 `config/upstream-lock.json` 记录。
- 功能说明集中在 `docs`；根目录只保留项目入口和配置文件。
