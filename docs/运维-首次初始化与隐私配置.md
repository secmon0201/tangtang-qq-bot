# 首次初始化与隐私配置

本仓库按“公开源码”和“本地实例”分层。公开仓库只包含代码、空配置模板、合成测试数据和说明文档；真实 QQ 号、群号、访问令牌、API 密钥、域名、个人署名、数据库、日志和登录状态只能留在本机。

## 第一次使用

双击 `启动工具\00-首次初始化设置.bat`。它只在 `.env` 不存在时复制 `.env.example`，已有 `.env` 永远不会被覆盖，然后用记事本打开本地配置。

也可以在 PowerShell 中执行：

```powershell
.\scripts\initialize_local_config.ps1
```

填写后先执行配置校验，再启动：

```powershell
.\.venv\Scripts\python.exe scripts\validate_qq_config.py --env .env
.\启动工具\01-启动全部.bat
```

## 必填的本地实例数据

| 配置项 | 填写内容 | 公开模板 |
| --- | --- | --- |
| `QQ_ACCOUNT_ID` | SnowLuma 当前登录的机器人 QQ 号 | 空 |
| `MANAGED_GROUP_IDS` | 首次迁移要管理的群号，英文逗号分隔 | 空 |
| `BOT_OPERATOR_IDS` | 超级管理员 QQ 号，英文逗号分隔 | 空 |
| `ONEBOT_ACCESS_TOKEN` | 与 SnowLuma 反向 WebSocket 一致的随机令牌 | 空 |

QQ 密码、二维码、验证码、滑块、短信、Cookie 和设备验证不写进 `.env`，仍由用户在 QQ/SnowLuma 中手工完成。

## 按功能填写

- 糖糖聊天：填写 `TANGTANG_API_KEY`，按需填写 `TANGTANG_GROUP_IDS`。API 地址和模型可保留模板默认值。
- 发言画像：填写 `PROFILE_API_KEY`；留空时按代码规则决定是否沿用糖糖接口。
- 私有集群：机器人启动并登记群后，由超级管理员私聊使用 `#系统设置 集群 创建/邀请` 建立；集群名称和成员只保存在 SQLite。
- 内部公告默认目标：需要本地内部公告接口时填写 `GLOBAL_ANNOUNCEMENT_DEFAULT_CLUSTER`；公告面板的逐次多选不依赖此项。
- 鸣潮历史导入：需要运行导入工具时填写固定的 `WUWA_IMPORT_CLUSTER_NAME`；工具只接受该 SQLite 集群范围。
- 固定测试群通知：填写 `CODEX_COMPLETION_NOTIFY_GROUP_ID`、`CODEX_COMPLETION_NOTIFY_SUPER_ADMIN_ID` 和独立令牌。
- QQ 官方 OpenAPI 备用链路：只有切换到该传输时才填写 `QQ_OPENAPI_APP_ID`、`QQ_OPENAPI_TOKEN`、`QQ_OPENAPI_APP_SECRET`。
- 固定公网入口：填写 `PUBLIC_SITE_BASE_URL`、`PUBLIC_SHORT_HOST`、`PUBLIC_TUNNEL_NAME`；个人署名放在 `PUBLIC_GENERATOR_CREDIT`。没有自有域名时全部留空，不影响本地机器人基础运行。

群功能的当前开关、群代称、私有集群关系和运行令牌以 `data/bot.db` 为准。数据库是本地运行数据，不放进模板，也不能上传。

## 公开前检查

每次准备公开提交前运行：

```powershell
.\.venv\Scripts\python.exe scripts\validate_public_release.py
```

检查器会确认 `.env.example` 的私有字段为空，并扫描 Git 候选文件中的本机实例值、真实风格的身份编号、Windows 用户目录、QQ 数据路径和常见凭据格式。CI 会在没有本机 `.env` 的环境中再执行一次静态检查。

`.gitignore` 只保护尚未被 Git 跟踪的文件，不能清除旧提交。当前包含历史的运维仓库应保持私有；真正公开时，从通过检查的工作树导出干净快照，在新目录中创建一次新的根提交，不复制 `.git` 历史。

## 不会上传的内容

`.env`、`data/`、SQLite、日志、报告、下载、备份、缓存、SnowLuma、GsUID.Core、Cloudflare 凭据和 QQ 登录状态均被排除。不要用 `git add -f` 绕过这些规则，也不要把故障日志或聊天截图直接贴进公开 issue。
