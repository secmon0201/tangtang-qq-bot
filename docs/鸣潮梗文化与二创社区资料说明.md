# 鸣潮数据库与梗文化资料说明

## 数据文件与检索服务

- 数据文件：`bot/resources/mingchao_meme_culture.json` 收录 36 条社区梗词条；`bot/resources/mingchao_official_knowledge.json` 收录 103 条中文官网优先的角色、术语、系统、地区与玩法词条。两份种子在启动时合并迁入 SQLite（`data/knowledge/knowledge.db`），当前合计 139 条。
- 检索服务：`bot/services/mingchao_meme_culture.py` 兼容原调用名，实际检索完整鸣潮数据库，提供 `entries()`、`search()`、`render_search()`；与枝江百科共用同一套 CJK 二元切词逻辑。
- 接入糖糖：命中时注入 `[本地鸣潮梗文化]` 段落，与 `[本地枝江知识]` 合计上限约 1200 字；检索只读取 `approved` 词条，审核收录的新词条即时生效。

## 边界与违禁品规则

- 角色、机制、世界观和版本资料以中文官方站与游戏内中文文本为准；本地 `E:\AI Project\wuwa_gpt` 仅作候选词与术语发现来源，不能单独成为事实依据。
- 只收录可追溯的公开社区梗，词条保留来源名称、URL 与适用说明；涉及强度/剧情争议的梗只记录传播语境，不评价角色本身。
- 与珈乐相关的词条即使进入本地库也标记为违禁品，不会进入检索结果或糖糖提示词；鸣潮梗库当前不含珈乐相关内容，检索时同样执行违禁过滤。
- 联网热更按仲裁链执行：本地已审核 > 联网经人工审核 > 联网待审 > 模型内部知识；提案先进入待审队列，不会自动覆盖本地词条。
- 文件化审核：待审队列见 `data/knowledge/收录待审.md`；通过的条目复制到 `收录确认.md`、不通过的复制到 `收录拒绝.md`，机器人每次启动处理并清空这两份文档，并从待审中移除已处理内容；拒绝内容会归档到 `收录拒绝归档.md`，后续重复内容自动拒绝。群内命令 `#收录待审` / `#收录确认 <编号>` / `#收录拒绝 <编号>` / `#收录恢复待审 <编号>`（仅超级管理员）是同一流程的快捷方式；归档文档只是数据库镜像，直接编辑不会生效。
- 重叠条目不重复存储：事实类词条以枝江百科为主，梗文化词条留在鸣潮梗库，两边通过 `related_ids` 交叉引用；同一事实不在两个库各存一份完整摘要。
- 梗文化随版本快速变化，后续扩充或修正词条后，跑 `tests/test_mingchao_meme_culture.py` 和 `tests/test_tangtang_chat.py` 再重启 NoneBot。
